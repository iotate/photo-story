# 中国写意

## 核心特征
- 提取照片主体、轮廓、姿态与叙事关系
- 重构为具有中国写意绘画气质的现代编辑画面
- 以少胜多、意到笔不到
- 经营位置、计白当黑、虚实相生与疏密聚散

## 风格DNA
1. **以少胜多**：不完整描摹照片，只保留真正值得记住的主题、隐喻和视觉关系
2. **意到笔不到**：主动删减背景和次要细节，用少量墨线、淡彩、色块与空白重新组织主体
3. **经营位置**：借鉴中国画的构图原则，保持现代平面设计的视觉重心与版式秩序
4. **计白当黑**：大面积有意义的空白，让留白成为构图的一部分
5. **手绘墨线**：纤细而有提按变化的手绘墨线，写意勾勒
6. **克制淡彩**：局部罩染、点染和色墨交融，保留纸面透气感与未完成感

## 技术参数

### 色彩参数
- 清雅、柔和、通透、略带灰度但不脏浊
- 极浅纸色为底
- 从原图提炼2-4种最具辨识度的颜色进行淡化、提纯和东方化处理
- 色彩不追求完整填满，以局部罩染、点染和色墨交融建立节奏
- 通过浓淡、冷暖、面积与留白形成层次
- 避免：高饱和撞色和满版着色

### 质感参数
- 底面：宣纸质感
- 线条：纤细而有提按变化的手绘墨线
- 断续变化：线条可以有断续、轻重、枯润、迟疑和自然手工误差
- 局部用稍重墨线稳定结构，其余边缘允许消失于留白
- 写意勾勒，不追求完整描摹

### 构图特征
- 位置经营：主体不必居中，可依照姿态、走势和叙事重心偏置、悬置、局部裁切
- 留白意义：让留白承担空气、距离、时间、静默和想象
- 单一叙事：只保留一个清晰主叙事，其余元素点到即止
- 现代秩序：保持现代平面设计的视觉重心与版式秩序

## 提示词模板
```
将照片转换为中国写意风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、姿态与叙事关系，只保留原画面真正值得记住的主题、隐喻和视觉关系，重构为具有中国写意绘画气质的现代编辑画面。不要完整描摹照片，而以"以少胜多、意到笔不到"的方式主动删减背景和次要细节，用少量墨线、淡彩、色块与空白重新组织主体，让人一眼认出原物，同时保留观察、想象与余韵。

【构图设计】
构图借鉴中国画的经营位置、计白当黑、虚实相生与疏密聚散，同时保持现代平面设计的视觉重心与版式秩序。主体不必居中，可依照自身姿态、走势和叙事重心偏置、悬置、局部裁切或集中于一侧；另一侧保留大面积有意义的空白，让留白承担空气、距离、时间、静默和想象。画面只保留一个清晰主叙事，其余元素点到即止，使"画到哪里、停到哪里"本身成为构图的一部分。

【绘画语言】
采用纤细而有提按变化的手绘墨线、写意勾勒与克制淡彩。线条可以有断续、轻重、枯润、迟疑和自然手工误差；局部用稍重墨线稳定结构，其余边缘允许消失于留白。色彩不追求完整填满，而以局部罩染、点染和色墨交融建立节奏，保留纸面透气感与未完成感。

【色彩系统】
配色根据照片的综合色温与最有生命力的特征色智能转译，不固定某一色系。整体保持清雅、柔和、通透、略带灰度但不脏浊，以极浅纸色为底，再从原图提炼2-4种最具辨识度的颜色进行淡化、提纯和东方化处理。主体关键色稍清晰，环境色迅速减弱，通过浓淡、冷暖、面积与留白形成层次，避免高饱和撞色和满版着色。

【文字融入】
文字应像传统题跋一样成为画面的一部分，而不是后期附加标题。根据照片的主体、情绪、动作、文化语境、时间感或隐喻，自由生成少量字、词、短句或片段，不固定语种、格式和内容。可沿主体走势、留白边缘、视觉轴线或画面一侧纵向排布，与绘画形成呼应、避让、穿插或对景关系。使用小型、疏朗、克制、略带提按顿挫与自然墨色变化的东方题跋式手写字体，可辅以极少量更现代、更细的编辑字体形成古今之间的层级，但不要菜单式排版、固定标题栏或大段说明。

【整体气质】
整体呈现应具有东方写意的留白与气韵、手绘线条的温度、淡彩设色的清雅，以及现代编辑设计的精确秩序。像一本当代艺术家重新编排的东方观察册，而不是传统国画复制品。避免完整写实描摹、满版背景、浓重水墨、工笔细描、仿古做旧、卡通国风、古风模板、贴纸拼贴、商业海报感和机械化排版。
```
