# 纸面叙事

## 核心特征
- 基于摄影作品制作3:4竖版的「第二世界」摄影二创海报，上下严格1:1分割
- 上半部分：尽可能忠实保留原照片，不改变主体、人物动作、空间关系、色彩和自然光影
- 下半部分：自然的暖米白纸张背景，保留大量留白，创造「第二世界」

## 风格DNA
1. **忠实保留**：上半部分忠实保留原照片，不改变主体、动作、空间、色彩和光影
2. **视觉结构**：找出最有辨识度的视觉结构，不只是识别题材
3. **第二世界**：让照片中的结构变成可以被触碰、使用或改变的东西
4. **真实互动**：手绘人物真正与照片中的物理结构互动，不是摆姿势
5. **自然旁白**：简短英文手写旁白，自然轻松有幽默感，不是励志语录
6. **发现本质**：不要装饰照片，先理解照片，再发现它里面原本就可能存在的另一个世界

## 技术参数

### 色彩参数
- 上半部分：保留原照片色彩
- 下半部分：自然的暖米白纸张背景

### 质感参数
- 真实摄影 + 米白纸张 + 极简黑线涂鸦
- 干净、明亮、克制
- 轻微手工拼贴感和独立杂志感

### 构图特征
- 3:4竖版，上下严格1:1分割
- 视觉结构识别：水波、道路、倒影、云层、枝条、光束、影子、建筑边缘等
- 第二世界创造：让照片中的结构变成可以被触碰、使用或改变的东西
- 手绘人物：0-3个极简黑色手绘线稿人物

### 剪贴形状设计
- 水：可以成为一块小水域
- 光：可以成为某种可被借用的东西
- 道路：可以继续延伸
- 云或树枝：可能形成新的空间关系
- 设计原则：具体答案必须从这一张照片本身产生

## 提示词模板
```
将照片转换为纸面叙事风格。

【核心设定】
基于上传的摄影作品，制作一张3:4竖版的「第二世界」摄影二创海报。整体严格上下1:1。

【上半部分】
尽可能忠实保留原照片，不改变主体、人物动作、空间关系、色彩和自然光影，只做必要的等比裁切。

【下半部分】
使用自然的暖米白纸张背景，保留大量留白。但不要直接套用"撕纸＋小人"的固定模板。生成之前，请先认真观察这张照片：

【视觉结构识别】
1. 找出照片里最有辨识度的视觉结构，而不只是识别题材。例如水波、道路、倒影、云层、枝条、光束、影子、建筑边缘、人物动作、山脊等。

2. 问自己："如果照片里的这个结构真的变成一种可以被触碰、使用或改变的东西，它最自然会是什么？"由此找到只属于这张照片的"第二世界"。可能发生的变化包括但不限于：拉、推、拨开、进入、打捞、测量、修补、展开、铺平、攀爬、连接、收集……但不要机械复用这些动作。

3. 摄影剪贴的形状本身也必须参与解释照片。不要默认使用普通不规则撕纸边。水可以成为一块小水域，光可以成为某种可被借用的东西，道路可以继续延伸，云或树枝也可能形成新的空间关系。具体答案必须从这一张照片本身产生。

4. 可以加入0-3个极简黑色手绘线稿人物。小人不是装饰，而是这个第二世界里的"使用者"。他们必须真正与照片中的物理结构互动，而不是站在旁边摆姿势。如果原照片已经有很强的人物动作，可以不新增小人。

5. 根据这张照片具体发生的事情，生成一句简短英文手写旁白。语气自然、轻松、有一点幽默或画外音感。不要写成励志语录，也不要重复"Same…,different…"这类固定句式。文字位置根据画面留白和动作方向决定，不固定在某个角落。

【整体风格】
真实摄影＋米白纸张＋极简黑线涂鸦，干净、明亮、克制、有轻微手工拼贴感和独立杂志感。

【避免】
商业广告感、复杂插画、密集小人、固定撕纸模板、重复动作、为了好看随意添加树叶星星等装饰、擅自改变原照片色彩或重新设计摄影内容。

【最重要的原则】
不要装饰照片。先理解照片，再发现它里面原本就可能存在的另一个世界。理想结果应该让人看到后觉得："原来这张照片本来就可以这样理解。"
```

## 适用场景
- 人物摄影：人物动作、人物互动、人物与空间关系
- 风景摄影：水波、道路、山脊、天空、自然结构
- 城市摄影：建筑边缘、街道、空间结构
- 建筑摄影：建筑结构、空间关系、几何线条
- 自然摄影：自然元素、光线、影子、枝条

## 反模式

- 商业广告感

- 密集小人
- 固定撕纸模板
- 重复动作
- 擅自改变原照片色彩或重新设计摄影内容
- 励志语录或固定句式
