# 大友克洋风格

## 核心特征
- 精细线条、机械细节、未来都市、破坏美学
- 以《阿基拉》等作品为代表的赛博朋克视觉风格
- 科技与末世的主题表达

## 风格DNA
- 极度精细的钢笔线条技法
- 复杂的机械结构与城市景观
- 霓虹色调与金属质感的结合
- 破坏与重构的视觉美学
- 赛博朋克的未来世界观
- 科技反思与人性探讨的深度

## 技术参数

### 色彩参数
- 主色调：霓虹色调、金属质感
- 典型色：霓虹粉、激光蓝、金属灰、警示红
- 饱和度：高饱和，高对比
- 对比度：极高对比，戏剧性强
- 色彩特征：霓虹光感与金属冷感

### 质感参数
- 线条：精细钢笔线，极度工整
- 网点：漫画网点效果
- 纹理：机械纹理、金属质感
- 细节：极其精细，甚至繁复
- 质感特征：硬朗、精密、工业化

### 构图特征
- 密集的城市景观
- 机械元素突出
- 动态与破坏感
- 未来感的空间营造
- 复杂的透视与结构

## 提示词模板
```
将照片转换为大友克洋风格。

【线条技法】
使用极度精细的钢笔线条，线条工整、精密，呈现复杂的机械结构与城市景观。

【色彩系统】
采用霓虹色调与金属质感：霓虹粉、激光蓝、金属灰、警示红。高饱和、高对比，营造赛博朋克的未来感。

【质感表现】
机械纹理、金属质感、漫画网点效果。细节极其精细，呈现繁复而有序的视觉层次。

【构图特征】
密集的城市景观、突出的机械元素、动态与破坏感。营造未来感的空间氛围。

【整体氛围】
呈现科幻末世、赛博朋克、科技反思、人性探讨的主题深度。视觉硬朗、精密、富有冲击力。
```
