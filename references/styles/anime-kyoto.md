# 京都动画风格

## 核心特征
- 清新色调、精致背景、人物细腻、光影柔和
- 以《轻音少女》《凉宫春日》等作品为代表
- 日常生活的美学化与细腻情感的表达

## 风格DNA
- 柔和清新的色彩基调
- 精致细腻的背景绘制
- 细腻的人物表情与动作
- 温暖治愈的光影氛围
- 日常生活场景的美学化
- 细腻情感的诗意表达

## 技术参数

### 色彩参数
- 主色调：淡雅清新色调
- 典型色：樱花粉、天空蓝、新绿、温暖橙
- 饱和度：中等，柔和舒适
- 对比度：低对比，温柔细腻
- 色彩特征：温暖、治愈、清新

### 质感参数
- 绘制：精致细腻的手绘质感
- 线条：柔和、干净、流畅
- 光影：空气感、透光感、柔和散射
- 整体：温暖治愈的视觉氛围
- 细节：精细而不繁复

### 构图特征
- 日常场景为主
- 人物细腻表现
- 环境与情感融合
- 光影氛围营造
- 留白与构图的平衡

## 提示词模板
```
将照片转换为京都动画风格。

【色彩系统】
采用淡雅清新的色调：樱花粉、天空蓝、新绿、温暖橙。色彩柔和舒适，呈现温暖治愈的氛围。

【人物表现】
人物造型细腻，表情与动作精致。保持柔和的轮廓线条，呈现青春的活力与细腻的情感。

【背景绘制】
精致细腻的背景绘制，日常场景美学化处理。空气感与透光感营造温暖的氛围。

【光影效果】
柔和散射的光影效果，透光感与空气感并重。光影服务于情感表达，营造治愈温暖的氛围。

【整体氛围】
呈现青春日常、细腻情感、治愈温暖、生活之美的主题基调。视觉柔和、精致、富有诗意。
```

## 适用场景
- 日常场景：校园、街道、室内、日常生活
- 人物肖像：青春主题、情感叙事、温馨人物
- 自然风景：樱花、天空、绿地、季节景色
- 建筑空间：学校、家庭、咖啡馆等生活空间

## 反模式
- 高对比的戏剧性光影
- 粗犷硬朗的线条风格
- 暗沉压抑的色彩氛围
- 复杂繁复的细节堆砌

## 故事感
- 青春日常
- 细腻情感
- 治愈温暖
- 生活之美
