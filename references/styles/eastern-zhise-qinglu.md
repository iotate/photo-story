# 只此青绿

## 核心特征
- 基于参考图生成简化版画风格的印记图像，采用青绿山水色彩系统
- 不保留原图照片，只提取主体结构转化为版画印记
- 不是整体色调变化，而是分元素类型分配色彩

## 风格DNA
1. **青绿色彩系统**：以石青、石绿为主色调，根据元素类型分配色彩
2. **绢本质感**：绢白/米白色绢本质感底色
3. **版画语言**：平涂色块、柔化边缘、负空间切割、稀疏线条
4. **分元素着色**：建筑/山体→石青蓝、石绿；水面→淡青、绢白；植被→石绿
5. **大量留白**：主体占画面宽度 35-55%
6. **宫廷富丽**：东方古典宫廷美学

## 技术参数

### 色彩参数
- 主色调：石青蓝 (#1A365D)、石绿 (#2F855A)
- 辅助色：赭石 (#8B7355)、朱砂红 (#C53030)
- 点缀色：金色 (#D69E2E)
- 底色：绢白或米白
- 特征：不同元素色彩分明，层次分明

### 质感参数
- 底面：绢本质感
- 颜料：矿物颜料，厚重与通透并存
- 整体：宫廷富丽感
- 印记风格：现代版画语言
  - 平涂色块
  - 柔化边缘
  - 负空间切割
  - 稀疏线条

### 构图特征
- 主体简化为可识别轮廓
- 大量留白
- 主体占画面宽度 35-55%

## 提示词模板
```
基于参考图生成只此青绿风格图像，灵感来自北宋王希孟《千里江山图》及舞蹈诗剧《只此青绿》。绢白或米白色绢本底色，使用现代版画语言呈现简化主体：平涂色块、柔化边缘、负空间切割、稀疏线条。主体简化为可识别轮廓，占画面宽度35-55%。大量留白。

色彩系统：采用青绿山水色彩，根据元素类型分配——建筑和主体结构用石青蓝、石绿；水面和流动元素用淡青、绢白或留白；植被用石绿；人物细节用赭石、金色点缀。整体呈现东方古典宫廷美学。禁止添加山、石、云、水等新元素，禁止整体色调统一变化，禁止泛黄、做旧、复古风格。
```

## 适用场景
- 建筑、地标、天际线、桥梁
- 有清楚轮廓、强光影的场景
- 适合制作系列艺术作品

## 反模式
- 整体色调变化或滤镜
- 传统青绿山水画（添加山、石、云、水等新元素）
- 泛黄、做旧、复古风格
- 保留摄影像素或照片写实区域

## 故事感
- 东方古典美学
- 宫廷富贵气象
- 山河入画
- 青绿永恒
