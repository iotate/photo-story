# 光影投影

## 核心特征
- 光线穿透形成的投影效果
- 柔和渐变的视觉质感
- 光与影的诗意表达

## 风格DNA
- 光线的穿透与折射
- 柔和渐变的边界处理
- 多重投影的叠加层次
- 光影的诗意氛围
- 虚实相生的视觉韵律
- 瞬间永恒的美学表达

## 技术参数

### 色彩参数
- 单色光：黑白投影，纯粹的光影对比
- 彩色光：RGB投影，色彩的分离与叠加
- 自然光：暖黄投影，温暖的日光氛围
- 饱和度：根据光源类型调整
- 色彩特征：柔和、渐变、有光感

### 质感参数
- 渐变：柔和过渡的光影渐变
- 边缘：模糊的边界轮廓
- 层次：透明叠加的多重投影
- 表面：光滑、有光泽感
- 整体：柔和、朦胧、有诗意

### 构图特征
- 光源方向与投影角度
- 多重投影的叠加组合
- 虚实对比的空间营造
- 光影节奏的视觉韵律
- 留白与光斑的平衡

## 提示词模板
```
将照片转换为光影投影风格。

【光影设计】
通过光线的穿透与折射，创造投影效果。投影边界柔和渐变，形成虚实相生的视觉韵律。

【色彩系统】
根据主题选择光源色彩：
- 单色光：纯粹的黑白光影对比
- 彩色光：RGB色彩的分离与叠加
- 自然光：暖黄的温暖日光氛围

【层次表现】
多重投影的叠加组合，营造丰富的视觉层次。透明叠加增加画面的深度与空间感。

【构图特征】
光源方向决定投影角度，光影节奏形成视觉韵律。留白与光斑的平衡，创造诗意的氛围。

【整体氛围】
呈现柔和、朦胧、有诗意的视觉质感。表达光影之美、瞬间永恒的主题基调。
```
