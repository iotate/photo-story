# 铅笔画

## 核心特征
- 石墨线条、铅笔阴影、纸张底纹
- 黑白灰色调
- 笔触纹理、轻重变化、擦拭痕迹
- 私密、创作过程、观察者视角

## 风格DNA
1. **石墨线条**：灰色调、粗细变化
2. **铅笔阴影**：斜线交叉表现
3. **纸张纹理**：可见素描纸纹理
4. **笔触方向**：可见运笔方向
5. **擦拭痕迹**：高光区有擦拭感
6. **柔和边缘**：柔化、有模糊过渡

## 技术参数

### 色彩参数
- 工具：石墨铅笔 (HB-6B)
- 线条：灰色调、粗细变化
- 阴影：斜线交叉表现
- 深浅：石墨密度决定

### 质感参数
- 纸张纹理：可见素描纸纹理
- 笔触方向：可见运笔方向
- 擦拭痕迹：高光区有擦拭感
- 边缘：柔化、有模糊过渡

### 铅笔硬度效果
- H系列：线条细腻、浅灰色、精确
- HB：中等深度、平衡
- B系列：线条深黑、粗犷、表现力强

### 构图特征
- 保留原图主体
- 线条勾勒
- 阴影表现
- 纸张质感

## 提示词模板
```
将照片转换为铅笔素描风格。保留原图的主体形状和构图布局，用细腻的铅笔线条重新呈现：石墨的深浅变化、阴影的晕染、纸张的纹理可见。线条有轻有重，保留了手绘时的停顿和犹豫感。
```
