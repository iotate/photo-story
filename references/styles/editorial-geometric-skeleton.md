# 几何骨架

## 核心特征
- 提取核心视觉母题，以圆、方、三角、弧线、轴线或重复比例建立严谨的几何架构
- 通过剪影、负形、局部放大、形态合并和符号化转译重构主体
- 兼具民俗图录、古物拓片与现代平面设计感的图形

## 风格DNA
1. **视觉母题**：提取核心视觉母题，不逐一翻译照片元素
2. **几何架构**：圆、方、三角、弧线、轴线或重复比例建立严谨几何架构
3. **图形转译**：剪影、负形、局部放大、形态合并和符号化转译
4. **印刷质感**：木刻拓印、干刷丝网印刷与旧式图录印刷的混合质感
5. **大面积留白**：远看结构明确，近看具有纸张、颗粒与印刷细节
6. **寓意先行**：传统文化感与现代设计秩序并存

## 技术参数

### 色彩参数
- 深色结构：以一个深色建立结构
- 主题色：搭配1-2个主题色
- 强调色：少量强调色
- 色彩来源：从原图提取
- 配色原则：配色清爽，不灰脏做旧

### 质感参数
- 混合质感：木刻拓印、干刷丝网印刷与旧式图录印刷的混合质感
- 质感细节：保留断墨、擦痕、露底和轻微套色偏差
- 清晰边界：重要轮廓与几何边界必须清晰
- 禁止使用：装饰堆砌、随机散点、颜色杂乱

### 构图特征
- 以圆、方、三角、弧线、轴线或重复比例建立严谨几何架构
- 大面积留白
- 远看结构明确，近看具有纸张、颗粒与印刷细节

## 提示词模板
```
将照片转换为几何骨架风格。

【核心设定】
分析照片中最具识别度的主体、轮廓、姿态、空间关系和情绪寓意，从中提取一个核心视觉母题，并以圆、方、三角、弧线、轴线或重复比例建立严谨的几何架构。通过剪影、负形、局部放大、形态合并和符号化转译，将主体重构为兼具民俗图录、古物拓片与现代平面设计感的图形。

【纸张与留白】
使用暖白色纹理纸张，整体保持大面积留白，远看结构明确，近看具有纸张、颗粒与印刷细节。

【配色系统】
配色从原图提取：以一个深色建立结构，搭配1-2个主题色和少量强调色。配色清爽，不灰脏做旧。

【印刷质感】
采用木刻拓印、干刷丝网印刷与旧式图录印刷的混合质感，保留断墨、擦痕、露底和轻微套色偏差，但重要轮廓与几何边界必须清晰。

【文字处理】
加入一个简短中文标题和一行小号英文注释，文字仅作为辅助信息，不抢夺主体。

【整体气质】
寓意先行、图形克制、几何严谨、拓印粗粝、配色清爽、留白清晰，传统文化感与现代设计秩序并存。

【避免】
逐一翻译照片元素、无意义传统纹样、装饰堆砌、随机散点、颜色杂乱、灰脏做旧、写实插画、模板感、大号文字、额外主体、拼贴感、Logo及水印。
```
