# 油画

## 核心特征
- 厚重笔触、颜料堆积、画布纹理
- 浓郁色彩、对比强烈
- 可见笔触、刮刀痕迹、画布底纹
- 经典、厚重、艺术价值

## 风格DNA
1. **厚重笔触**：明显可见的笔触
2. **颜料堆积**：有立体感
3. **画布纹理**：可见底纹
4. **浓郁色彩**：浓郁、覆盖性强
5. **强烈对比**：对比强烈
6. **刮刀痕迹**：可能留痕迹

## 技术参数

### 色彩参数
- 特性：浓郁、覆盖性强
- 对比：强烈
- 饱和度：高
- 层次：厚重色层

### 质感参数
- 笔触：明显可见
- 画布纹理：可见底纹
- 颜料厚度：有立体感
- 刮刀：可能留痕迹

### 风格变体
- 古典：光滑表面、细腻渐变
- 印象派：明显笔触、光色表现
- 表现主义：粗犷笔触、夸张色彩

### 构图特征
- 保留原图主体
- 厚重笔触
- 色彩浓郁
- 画布质感

## 提示词模板
```
将照片转换为油画风格。保留原图的主体形态和构图，用厚重笔触呈现：颜料堆积感、画布纹理清晰、色彩浓郁。整体呈现经典艺术质感。
```
