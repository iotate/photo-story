# 潘通相框海报

## 核心特征
- 白色相框、主体自然穿框、低饱和背景、潘通式色号标签
- 高级编辑感的摄影海报设计
- 三层空间关系：背景、框内照片、框前主体
- 克制的穿框效果

## 风格DNA
1. **白色相框**：白色或暖白色相框
2. **主体穿框**：主体的关键部分自然突破相框边界
3. **低饱和背景**：从照片主色提取，高明度、低饱和
4. **潘通色号**：1-4种视觉近似潘通色号标注
5. **三层关系**：背景层、相框内照片层、穿框元素层
6. **高级编辑感**：干净、克制、高级

## 技术参数

### 色彩参数
- 相框：白色或暖白色
- 背景：从照片主色提取，高明度、低饱和
- 色号标注：1-4种视觉近似潘通色号
- 整体：低对比、柔和、高级感

### 质感参数
- 照片：真实摄影质感，保持清晰
- 阴影：轻微接触阴影
- 文字：清晰无衬线、单层纯黑
- 整体：干净、克制、高级

### 构图特征
- 三层关系明确：背景层、相框内照片层、穿框元素层
- 必须有元素穿出相框：选择主体的关键部分自然突破相框边界
- 穿框元素要有轻微接触阴影，增强立体感
- 底部保留充足文字区域
- 画布四周安全留白

### 文字规则
- 格式：`2995 C · COASTAL BLUE`（潘通色号 + 简洁英文色名）
- 字体：无衬线字体
- 颜色：单层纯黑
- 禁止：倒影、投影、光晕、浮雕、模糊重影

### 不同主体的处理
- 荷花和叶片：保留纹理清晰度，少量置于相框前
- 海浪和沙滩：少量浪尖跨出内框，海平线稳定
- 云层和晚霞：云缘断续、松散、自然
- 花朵和树枝：保留主干和自然生长方向
- 人物和动物：最清楚的轮廓或动态穿框
