# 东方故事

## 核心特征
- 基于参考图生成简化版画风格的印记图像
- 不保留原图照片，只提取主体结构转化为版画印记
- 暖象牙白/米白色纸张底色
- 保留原图特征性色彩，调整为东方美学色调
- 现代版画语言 + 东方克制美学

## 风格DNA
1. **版画印记**：完全重新生成的版画风格图像，保留特征性色彩
2. **纸张底色**：暖象牙白、米白色纸张质感
3. **东方色调**：朱砂红、石青蓝、赭石褐、藤黄等传统色彩
4. **大量留白**：主体占画面宽度 35-55%
5. **现代版画语言**：平涂色块、柔化边缘、负空间切割、稀疏线条

## 技术参数

### 色彩参数
- 底色：暖象牙白 #F5F0E6、米白色 #FAF8F5
- 特征性色彩：保留原图的主要色彩，调整为东方美学色调
  - 红色系 → 朱砂红 #C53030、胭脂红
  - 蓝色系 → 石青蓝 #1A365D、靛蓝
  - 黄色系 → 藤黄 #D69E2E、赭石褐
  - 绿色系 → 石绿、青碧
  - 紫色系 → 紫檀、青莲
- 禁止：泛黄、做旧、复古色调、完全黑白化

### 质感参数
- 画面质感：干净纸张质感，轻微纹理，不喧闹
- 印记风格：现代版画语言
  - 平涂色块（solid color blocks）
  - 柔化边缘（softened edges）
  - 负空间切割（negative-space cuts）
  - 稀疏线条（sparse lines）
  - 有节制的断点（measured breaks）
- 留白：大量留白，印记不填满画面
- 禁止：厚重纹理、粗糙颗粒、仿旧效果

### 构图特征
- 布局：竖版图像，单一画面
- 主体形态：一个清晰可识别的主体印记（占画面宽度 35-55%）
- 辅助印记：极少量支持性印记（基座线条、地平线/地面、比例标记）
- 细节转换规则：
  - 屋顶层次 → 2-4 条堆叠弧线，保留原有色彩
  - 窗户 → 3-5 个稀疏小点或短切口
  - 人物 → 3-8 个小垂直刻痕（无脸、无细节）
  - 水面 → 1-2 条水平残留线
  - 天空/光 → 保留为纸张留白，或用淡雅色彩暗示

## 提示词模板
```
基于参考图生成东方故事风格图像。

画面要求：
- 竖版图像，暖象牙白或米白色纸张底色
- 使用现代版画语言呈现简化的主体
- 大量留白，主体占画面宽度 35-55%

色彩处理：
- 保留原图的特征性色彩
- 调整为东方美学色调（朱砂红、石青蓝、赭石褐、藤黄等）
- 色彩简洁、雅致，不喧闹

印记风格：
- 平涂色块，保留特征性色彩
- 柔化边缘，不锐利
- 负空间切割，留白充分
- 稀疏线条，细节极少

风格禁止：
- 禁止泛黄、做旧、复古摄影风格
- 禁止银盐相纸、手工上色
- 禁止厚重纹理、粗糙颗粒
- 禁止完全黑白化、失去特征性色彩
- 禁止复杂细节、装饰元素

整体呈现：东方美学意境、诗意化色彩、留白之美。
```
