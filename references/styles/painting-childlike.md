# 童真插画

## 核心特征
- 提取照片主体、轮廓、姿态与叙事关系，重构为童真、松弛、克制的手绘编辑插画
- 略显笨拙的黑色手绘线条 + 简单柔和的平涂色块
- 独立出版气质：童真、聪明、轻松、治愈、专业编辑判断

## 风格DNA
1. **主体提取**：提取最具识别性的主体、轮廓、姿态与叙事关系
2. **手绘线条**：略显笨拙的黑色手绘线条，纤细、直接、不完全稳定
3. **平涂色块**：简单、柔和、略带手工覆盖感的平涂色块
4. **留白构图**：重视留白、视觉重心、尺度变化、方向关系与图文节奏
5. **文字融合**：文字与插画共同完成叙事，手写字体、自然不工整
6. **独立出版气质**：童真、聪明、轻松、治愈、专业编辑判断

## 技术参数

### 色彩参数
- 从原图提炼3-6种最有生命力和辨识度的颜色
- 转化为柔和、清透、略微去饱和的平涂色块
- 保留1-2处更鲜明的原图特征色作为视觉强调
- 整体轻盈、治愈、干净，不做脏旧滤镜

### 质感参数
- 纤细、直接、不完全稳定的黑色手绘线条
- 轻微抖动、停顿、断开和随手修正感
- 简单、柔和、略带手工覆盖感的平涂色块
- 极度浅、接近白色的柔和纸张底色，带非常轻微的天然纸纹

### 构图特征
- 留白优先：不要把插画填满整个区域，保留大片安静空间
- 主体偏置：主体可以偏置、缩小、局部裁切或沿某个方向展开
- 视觉重心：次要元素只用于帮助叙事，不喧宾夺主
- 图文节奏：文字可以落在主体下方、进入留白、顺着动作方向排列

## 提示词模板
```
将照片转换为童真插画风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、姿态与叙事关系。理解原画面真正值得记住的情绪、隐喻和故事。不要完整复刻场景，只保留最有意义的主体关系与少量环境线索，以概括比例、简化形体、手绘黑线和平涂色块重新叙述原画面，让人一眼认出原物，又带有记忆经过重新整理后的趣味与余味。

【手绘线条】
使用略显笨拙的黑色手绘线条勾勒关键结构。线条纤细、直接、不完全稳定，带轻微抖动、停顿、断开和随手修正感。复杂建筑、植物、人物、动物或器物主动概括，不描绘繁琐细节，让少量黑线成为画面的节奏和骨架。

【平涂色块】
搭配简单、柔和、略带手工覆盖感的平涂色块。从原图提炼3-6种最有生命力和辨识度的颜色，转化为柔和、清透、略微去饱和的平涂色块，并保留1-2处更鲜明的原图特征色作为视觉强调。整体轻盈、治愈、干净，不做脏旧滤镜。

【留白构图】
构图重视留白、视觉重心、尺度变化、方向关系与图文节奏。不要把插画填满整个区域，主体可以偏置、缩小、局部裁切或沿某个方向展开，并在周围保留大片安静空间；次要元素只用于帮助叙事。画面应像经过认真编辑后的随手画，而不是儿童画满整张纸。

【背景与色彩】
背景根据原图综合色温智能匹配一个极度浅、接近白色的柔和纸张底色，带非常轻微的天然纸纹。

【文字融合】
文字根据照片真正传达的动作、情绪、关系、记忆或隐喻自由生成，不固定标题形式、内容、语种或位置。可以是一句话、几个词或极短片段，既可以落在主体下方，也可以进入留白、顺着动作方向排列、贴近图形或与线条形成呼应，使文字与插画共同完成叙事。使用小型、松弛、略带稚拙书写误差的手写字体，笔画保持自然、不工整但可读，像画完之后自然写下的一句观察或感受，而不是后期添加的商业字体。

【整体气质】
整体呈现童真、聪明、轻松、治愈、略带笨拙却具有专业编辑判断的独立出版插画气质。避免完整场景复刻、细节堆积、粗黑卡通描边、规整矢量、儿童贴纸感、3D质感、商业模板感和无意义装饰。
```
