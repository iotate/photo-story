# 泛黄信纸照片

## 核心特征
- 打印在老旧信纸上的照片
- 米黄色底、褪色墨水
- 纸张纹理、墨迹晕染、褶皱痕迹
- 私密、手边物、日常珍藏

## 风格DNA
1. **老旧信纸**：米黄/淡黄色纸张底色
2. **褪色墨水**：褪色深褐/灰黑色
3. **纸张纹理**：可见纤维纹理
4. **褶皱痕迹**：随机折痕
5. **墨迹晕染**：边缘模糊扩散
6. **不规则边缘**：撕裂或磨损

## 技术参数

### 色彩参数
- 底色：米黄/淡黄色
- 墨水：褪色深褐/灰黑色
- 饱和度：极低

### 质感参数
- 纸张纹理：可见纤维纹理
- 褶皱：随机折痕
- 墨迹晕染：边缘模糊扩散
- 边缘：不规则撕裂或磨损

### 构图特征
- 保留原图主体位置
- 自然老化效果
- 手边物感

## 提示词模板
```
将照片转换为泛黄信纸照片风格。呈现一张打印在老旧信纸上的照片：米黄色纸张底色，褪色的墨水，可见的纸张纤维纹理，随机的褶皱痕迹，墨迹边缘有晕染效果，边缘不规则撕裂或磨损。整体呈现私密、手边物、日常珍藏的感觉。
```
