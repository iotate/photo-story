# 新国潮风格

## 核心特征
- 国风元素、现代设计、潮流感、年轻化
- 融合传统与现代的视觉表达
- 文化自信的设计语言与年轻态的东方美学

## 风格DNA
- 传统元素的现代化演绎
- 国风与潮流的融合设计
- 鲜明强烈的色彩对比
- 年轻化的东方美学表达
- 文化自信的视觉语言
- 传统纹样的创新运用

## 技术参数

### 色彩参数
- 主色调：国潮配色
- 典型色：朱砂红、霓虹紫、科技蓝、金色
- 饱和度：高饱和，鲜明醒目
- 对比度：高对比，视觉冲击力强
- 色彩特征：传统与现代的碰撞

### 质感参数
- 设计：扁平与立体结合
- 元素：传统图案现代化处理
- 质感：现代科技感与传统文化感并存
- 渐变：丰富渐变增强潮流感
- 细节：精致而富有设计感

### 构图特征
- 现代设计构图法则
- 传统元素现代化排列
- 潮流感强的视觉节奏
- 年轻化的表达方式
- 对称与不对称的平衡

## 提示词模板
```
将照片转换为新国潮风格。

【元素设计】
提取照片主体，融入传统国风元素进行现代化演绎。传统图案现代化处理，保持文化内涵的同时增强潮流感。

【色彩系统】
采用国潮配色：朱砂红、霓虹紫、科技蓝、金色。色彩鲜明醒目，呈现传统与现代的碰撞。

【设计风格】
扁平与立体结合，传统元素现代化排列。丰富渐变增强潮流感，整体精致而富有设计感。

【构图特征】
现代设计构图法则，潮流感强的视觉节奏。年轻化的表达方式，呈现文化自信。

【硬性禁止】
禁止添加任何文字元素（标题、标语、品牌名、标语口号等）。禁止添加书法字体、印章文字、汉字装饰。仅保留纯视觉图像内容。

【整体氛围】
呈现东方潮流、年轻态度、文化自信、时代精神的主题基调。视觉鲜明、潮流、富有文化底蕴。
```
