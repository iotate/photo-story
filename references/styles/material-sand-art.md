# 沙画

## 核心特征
- 散点构成、边缘模糊、流动感
- 沙土色调或彩色沙粒
- 颗粒感、渐变、指痕
- 转瞬即逝、表演性、无常

## 风格DNA
1. **散点构成**：边缘模糊、无清晰边缘
2. **流动感**：有动感
3. **颗粒感**：可见沙粒质感
4. **指痕**：手指划过的痕迹
5. **堆砌**：高低不一
6. **易逝感**：有种不稳定感

## 技术参数

### 色彩参数
- 沙土色：土黄、褐色、灰色
- 彩色沙：有限配色
- 渐变：沙粒密度变化
- 明暗：沙粒密度决定

### 质感参数
- 颗粒：可见沙粒质感
- 指痕：手指划过的痕迹
- 堆砌：高低不一
- 易逝：有种不稳定感

### 构图特征
- 散点构成
- 边缘模糊
- 流动感
- 颗粒质感

## 提示词模板
```
将照片转换为沙画风格。保留原图的主体形状和布局，但用细沙粒堆砌呈现：边缘是散落的沙点、颜色渐变、有种手在沙盘上作画的痕迹。整体呈现转瞬即逝的美感。
```
