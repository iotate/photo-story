# 透明解析

## 核心特征
- 提取照片主体、轮廓、姿态与叙事关系，重构为透明结构蓝图与高级技术图解
- 保留主体清晰可辨的外部轮廓，同时将部分表层转化为半透明、剖切、分层或透视状态
- 工程图纸、X-ray透视图、科学图解与未来档案的视觉语言

## 风格DNA
1. **透明结构**：显露最具代表性的内部结构、连接关系、材料层次、运动路径或空间逻辑
2. **工程蓝图**：工程图纸、X-ray透视图、科学图解与未来档案的视觉语言
3. **分层透视**：通过透明叠层、局部放大、剖面切片、爆炸分解建立视觉秩序
4. **结构标注**：极细轴线、尺寸线、节点编号、局部框选与小型结构示意
5. **单色蓝图**：清透、明亮、偏商务感的单色蓝图体系，不固定使用蓝色
6. **技术注释**：文字转化为技术注释与编辑排版的一部分

## 技术参数

### 色彩参数
- 单色蓝图体系：清透、明亮、偏商务感
- 色系选择：清晰的蓝、绿、红、橙、紫或中性色系，不固定使用蓝色
- 配色原则：浅色背景、一个主线色和少量深浅变化
- 色彩质感：干净、理性、有光感
- 层次建立：通过透明叠层、线条密度和局部高亮建立层次
- 避免：脏灰、暗沉、霓虹赛博和复杂多色

### 质感参数
- 工程图纸质感
- X-ray透视图质感
- 科学图解质感
- 未来档案感

### 构图特征
- 以主体为唯一核心
- 通过透明叠层、局部放大、剖面切片、爆炸分解、结构引线和精细标注建立视觉秩序
- 信息围绕主体自然展开
- 不同层级通过线宽、透明度、虚实与疏密区分
- 大面积干净留白和清晰阅读路径

## 提示词模板
```
将照片转换为透明解析风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、姿态与叙事关系。保留主体清晰可辨的外部轮廓，同时将部分表层转化为半透明、剖切、分层或透视状态，显露其最具代表性的内部结构、连接关系、材料层次、运动路径或空间逻辑，形成一种介于工程图纸、X-ray透视图、科学图解与未来档案之间的视觉语言。

【内部结构解释】
不要机械堆砌零件，而应根据主体自身属性决定"内部结构"如何被解释：
- 器物：表现组件与连接
- 建筑：表现空间与构造
- 交通工具：表现动力与结构
- 植物：表现枝脉与生长
- 动物或人物：以姿态骨架、动作轨迹、服装层次或抽象结构表达，避免血肉化解剖

【构图设计】
构图以主体为唯一核心，通过透明叠层、局部放大、剖面切片、爆炸分解、结构引线和精细标注建立视觉秩序。可加入极细轴线、尺寸线、节点编号、局部框选与小型结构示意，让信息围绕主体自然展开；不同层级通过线宽、透明度、虚实与疏密区分，保持大面积干净留白和清晰阅读路径，避免复杂科技UI和满版信息堆积。

【单色蓝图系统】
配色从照片中提取最具辨识度和精气神的主色，转化为清透、明亮、偏商务感的单色蓝图体系，以浅色背景、一个主线色和少量深浅变化完成整体。可以是清晰的蓝、绿、红、橙、紫或中性色系，不固定使用蓝色；颜色应干净、理性、有光感，通过透明叠层、线条密度和局部高亮建立层次，避免脏灰、暗沉、霓虹赛博和复杂多色。

【文字融入】
文字转化为技术注释与编辑排版的一部分。从照片的主体身份、功能、状态、动作或象征意义中提炼简短标题，并搭配少量结构编号、部件名称、状态词、尺度标记、方向说明或微型注释。文字通过引线、标尺、箭头、局部框选、纵排或边缘排版与主体发生精确关系，像工程草图中的说明系统，同时保持高级杂志式的克制与留白，不使用年份，不写大段说明。

【整体气质】
整体呈现透明结构、精密线稿、分层显影、工程秩序与编辑美学结合的高级视觉气质。无论主体是人物、动物、植物、建筑、器物、交通工具或自然对象，都应做到一眼可辨、结构有理、信息克制、层次清晰，避免普通线稿、廉价科幻HUD、过度机械化、复杂零件堆积、固定蓝色和模板感。
```
