# 剪纸

## 核心特征
- 剪影效果、镂空纹样、平面装饰
- 单色或多色剪纸
- 剪刀痕迹、连接点
- 民间艺术、节日、童趣

## 风格DNA
1. **剪影效果**：剪影、镂空
2. **连接点**：必需连接点
3. **剪刀痕迹**：边缘略微毛糙
4. **层次**：平面或多层
5. **纸张厚度**：可见纸张厚度
6. **折叠痕迹**：可能有折叠痕迹

## 技术参数

### 色彩参数
- 单色：传统红色或黑色
- 彩色：有限配色
- 对比：通常高对比

### 质感参数
- 纸张：剪纸专用纸质感
- 边缘：略微毛糙
- 折痕：可能有折叠痕迹
- 厚度：可见纸张厚度

### 构图特征
- 剪影效果
- 镂空纹样
- 连接点
- 平面装饰

## 提示词模板
```
将照片转换为剪纸风格。保留原图的主体形态，用剪纸特有的剪影和镂空呈现：清晰的轮廓剪影、镂空纹样、可见的剪刀痕迹和连接点。可以是单色（传统红色或黑色）或多色，整体呈现民间艺术的感觉。
```
