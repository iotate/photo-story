# 风格转换技术细节参考

本文件提供各种风格的技术参数和转换细节，确保风格化转换的质量和一致性。

## 核心原则

### 结构保留清单

在所有风格转换中必须保留：

1. **主体位置**：主要元素在画面中的相对位置不变
2. **大小比例**：元素之间的大小关系不变
3. **构图框架**：三分、对称、中心等构图结构不变
4. **空间层次**：前景、中景、背景的关系不变
5. **轮廓识别**：主体的外形能够被识别

### 风格转换清单

在风格转换中必须改变：

1. **色彩系统**：色调、饱和度、对比度根据风格调整
2. **质感细节**：纹理、颗粒、笔触根据风格添加
3. **线条处理**：清晰度、风格化程度根据风格调整
4. **边缘处理**：锐利、柔和、风格化边缘

## 一、东方故事风格（默认）

### 东方故事

**核心特征：**
- **基于参考图生成简化版画风格的印记图像**
- 不保留原图照片，只提取主体结构转化为版画印记
- 暖象牙白/米白色纸张底色
- **保留原图特征性色彩，调整为东方美学色调**
- 现代版画语言 + 东方克制美学

**关键区别（避免误读）：**
- ❌ 不是整张照片做旧、泛黄或上色
- ❌ 不是银盐相纸、手工上色、复古摄影
- ❌ 不是纯黑白或深墨色印记
- ✅ 是完全重新生成的版画风格图像，保留特征性色彩

**结构参数：**
- 布局：竖版图像，单一画面
- 底色：暖象牙白 #F5F0E6、米白色 #FAF8F5、或安静的源光色调
- 整体：纸张质感的平面，承载简化的主体印记

**色彩参数：**
- 底色：暖象牙白、米白色
- **特征性色彩**：保留原图的主要色彩，调整为东方美学色调
  - 红色系 → 朱砂红 #C53030、胭脂红
  - 蓝色系 → 石青蓝 #1A365D、靛蓝
  - 黄色系 → 藤黄 #D69E2E、赭石褐
  - 绿色系 → 石绿、青碧
  - 紫色系 → 紫檀、青莲
- **禁止**：泛黄、做旧、复古色调、完全黑白化

**质感参数：**
- 画面质感：干净纸张质感，轻微纹理，不喧闹
- 印记风格：现代版画语言
  - 平涂色块（solid color blocks）
  - 柔化边缘（softened edges）
  - 负空间切割（negative-space cuts）
  - 稀疏线条（sparse lines）
  - 有节制的断点（measured breaks）
- 留白：大量留白，印记不填满画面
- **禁止**：厚重纹理、粗糙颗粒、仿旧效果

**印记语法：**
- 主要形态：一个清晰可识别的主体印记（占画面宽度 35-55%）
- 辅助印记：极少量支持性印记
  - 基座线条
  - 地平线/地面
  - 比例标记（人物用小垂直刻痕）
- 细节转换规则：
  - 屋顶层次 → 2-4 条堆叠弧线，保留原有色彩
  - 窗户 → 3-5 个稀疏小点或短切口
  - 人物 → 3-8 个小垂直刻痕（无脸、无细节）
  - 水面 → 1-2 条水平残留线
  - 天空/光 → 保留为纸张留白，或用淡雅色彩暗示
- **禁止**：复杂细节、装饰性元素、写实描绘

**风格参照：**
- 现代平面设计中的极简版画
- 东方美学的留白与克制
- 传统中国画色彩体系
- 编辑设计中的系列艺术海报
- **不是**：复古摄影、手工上色、银盐工艺、纯黑白版画

**故事感：**
- 东方美学的诗意化呈现
- 安静、克制、有呼吸感
- 可重复的系列识别度
- 画廊标签般的诗意（可选小标题）

**适用场景：**
- 建筑、地标、天际线、桥梁
- 有清楚轮廓、强光影的场景
- 旅行、城市、自然景观
- 适合制作系列艺术作品

**提示词示例：**
```
基于参考图生成东方故事风格图像。

画面要求：
- 竖版图像，暖象牙白或米白色纸张底色
- 使用现代版画语言呈现简化的主体
- 大量留白，主体占画面宽度 35-55%

色彩处理：
- 保留原图的特征性色彩
- 调整为东方美学色调（朱砂红、石青蓝、赭石褐、藤黄等）
- 色彩简洁、雅致，不喧闹

印记风格：
- 平涂色块，保留特征性色彩
- 柔化边缘，不锐利
- 负空间切割，留白充分
- 稀疏线条，细节极少

风格禁止：
- 禁止泛黄、做旧、复古摄影风格
- 禁止银盐相纸、手工上色
- 禁止厚重纹理、粗糙颗粒
- 禁止完全黑白化、失去特征性色彩
- 禁止复杂细节、装饰元素

整体呈现：东方美学意境、诗意化色彩、留白之美。
```

**变体配方：**

印记语法：
- 墨章建筑：块状形态 + 负空间切割 + 特征性色彩
- 堆叠秩序：弧线、条带、台阶简化为 3-5 个层次，保留色彩
- 天际线记忆：地标主形态 + 2-3 辅助条 + 地平线
- 光影遗珍：主体剪影轻压入柔和光场，保留淡雅色彩
- 边缘残留：4-6 条果断边缘聚集成可识别图案

色彩重量：
- 雅致色块：保留特征性色彩，调整为东方美学色调（默认）
- 淡彩：色彩更淡雅、含蓄
- 重彩：色彩更浓郁、有力量
- 单色：仅用一种特征色 + 纸张底色

## 四、编辑设计风格

### 扁平海报风格

**核心特征：**
- 朴素民间艺术印刷语言，平静、密集、扁平的海报
- **保留原图的内容布局和主体结构**，仅转换视觉风格
- 不删除或新增原图中没有的主要元素

**五大标志性原则：**
1. **世界是平摊的**：地面呈现为从上方观看的倾斜地图式色块，而树木、人物、建筑、车辆以扁平立面直立呈现。无消失点，无汇聚线，无3D效果。
2. **密纹成静**：平静来自密集、均匀、手工的质感——而非空白极简。抽象通过微缩实现，而非删减。
3. **色窄成静**：每幅图像使用纸白、暖墨黑，以及仅2-4种克制的、墨感的区域色。密集的场域保持安静，因为颜色保持稀少而柔和。
4. **一枚亮色**：每幅图像恰好使用一种饱和色——任意色相，是全图唯一的高饱和色，且总是承担构图任务（焦点物体或结构线颜色）。
5. **人是刻度**：微小的无面人物做着日常事务，赋予场景尺度、节奏和温度。

**透视规则（硬性约束）：**
- 地面区域从上方观看，扁平如手绘地图
- 树木、人物、建筑、车辆以简单的扁平立面（侧面或正面视图）直立在这些区域上，如儿童画或民间地图
- 无消失点、无汇聚线、无透视缩短、无地平线大气
- 距离仅可通过轻微的尺寸缩小和在画布上较高的位置来表现
- 无物投下阴影。光线均匀且无方向

**质感语法：**
每个颜色区域恰好承载一种质感系统，在该区域内节奏和密度均匀：
- **窗户点阵**：用于建筑群的小矩形/点状窗户阵列；每个立面是略微不同的手绘网格
- **缝线虚线**：用于水面、草地、铺装的短平行虚线或手工刻痕；方向跟随区域的流动
- **编织丝网颗粒**：一种整体织物般的丝网印刷颗粒，可覆盖整幅图像
- **树冠涂鸦块**：用于树冠的密集环状/刻痕块——树冠是填充的深色块，绝非仅线条的叶丛或骨架轮廓；树干是单根自信的线条
- **纯墨轮廓**：用于人物、车辆、长椅、道具的干净抖动手绘线；最少的内部细节

**质感规则：**
- 绝不在一个区域内混合两种质感系统
- 绝不让质感密度在区域内漂移
- 质感是手工的，笔触略有不规则，但整体节奏均匀
- 所有质感是纸上的不透明平涂墨色：无渐变、无透明度坡度、无绘画式融合

**色彩系统：**

固定锚点（每幅图像）：
- **纸白**：带有可见颗粒的暖色米白纸；也可用作区域色（天空、散步道、雪、沙）
- **墨黑**：用于所有轮廓、人物、窗户网格和深色区域的暖近黑色

区域色彩（每幅图像全新选择）：
- 从场景推导：季节、时间、气候、材料
- 保持每种区域色低至中等饱和度，墨感，印刷感
- 典型色域：深瓶绿、鼠尾草绿、普鲁士海军蓝、炭靛蓝、暖灰褐、赭石卡其、尘砖色、板岩蓝、深橄榄绿
- 保持组合狭窄：相关或相邻色相讲述一个色彩故事。绝无彩虹

高光引擎：
- 每幅图像恰好一种饱和高光色——全图唯一的高饱和色
- 可以是任何色相：朱红、番茄红、万寿菊黄、钴蓝、翠鸟蓝、品红、黄绿色
- 承担构图任务：焦点物体（约画布1-6%）或结构线颜色（约画布3-10%）
- 移除测试：心理删除高光，如果视线路径、平衡和场景小故事保持不变，它就是装饰——重新设计它

**人物系统：**
- 人物是小型实心剪影，**绝非火柴人**
- 每人约画布高度的1.5-5%，由3-7个填充平涂形状组成
- 实心躯干、有可见宽度的四肢、实心块状或点状头部
- 细线四肢和轮廓圆头（火柴人）是风格的硬性失败
- 绝无面部特征。头部是实心空白点或简单填充形状；身份来自姿态和活动
- 从场域卡片中绘制活动中的他们：提着包行走、踩踏板、扔球、坐着阅读、遛狗
- 僵硬、认真、仿朴素——绝不可爱、绝不Q版、绝无卡通比例
- 散布3-20个人物，间距不均、方向各异
- 服装是从区域色调和锚点中选取的不透明平涂填充

**构图家族：**
- **分层地带**（默认）：世界堆叠为2-5个水平或轻微对角的平涂色带。空间是地质，而非透视。色带可倾斜5-20°以产生动感。
- **图鉴散点**：元素漂浮在开放的纸面上，如目录页——各自独立绘制，无共享地面，无统一透视。保持约40-65%的开放纸面。

**布局规则：**
- 仅2-5个区域。一个区域应占主导（约占画布35-60%）；无偶然的50/50分割
- 建立一条视线路径：从最大区域的最密集角落进入，遇见高光，沿着主导动势移动，从较安静的区域退出
- 密度对撞：将极度密集的质感块直接压在简洁的平涂区域旁。对比本身就是戏剧；不要用渐变或雾气软化边界

**硬性禁止：**
- 线性透视、消失点、透视缩短、地平线雾气、大气深度
- 3D渲染、投射阴影、软阴影、渐变
- 光滑矢量清洁感、绘画笔触、水彩晕染
- 摄影像素或质感、照片写实区域、电影光线、景深
- 人物面部特征、火柴人、细线四肢或线描人物
- 真人肖像、可爱卡通/Q版/动漫比例、儿童读物甜美感
- 第二套饱和色系统、彩虹或糖果色调、柔和色调
- 默认角落日月圆盘、从示例复制的色相或母题
- 霓虹、分层地带中的稀疏白色极简
- 区域内的不均匀或混合质感
- 浅色区域上的白色贴纸轮廓

**故事感：**
- 朴素民间艺术
- 密集而安静
- 从容日常
- 友善的距离

- 把照片重新压缩成色块、轮廓、halftone网点
- 删除不重要的信息，只留下一个视觉锚点

**设计流程：**
1. **找出视觉主体**：识别照片中真正的视觉主体
2. **分析关系**：分析动作、方向和空间关系
3. **删除信息**：删除不重要的信息，只留下一个视觉锚点
4. **压缩重构**：把照片重新压缩成色块、轮廓、halftone网点
5. **增加文字**：简明扼要的标题 + 有文艺范的一两句短句

**视觉处理：**
- 色块：简化的色块表现
- 轮廓：清晰的轮廓线
- halftone网点：半色调网点效果
- 视觉锚点：单一视觉焦点

**文字规则：**
- 位置：留白处
- 内容：简明扼要的标题 + 有文艺范的一两句短句
- 数量：不要太多文字
- 风格：文艺范、现代平面设计感

**故事感：**
- 报纸美学
- 信息压缩
- 视觉锚点
- 现代平面设计

### 布艺拼贴

**核心特征：**
- 用格纹棉布、亚麻和水洗粗麻布碎料裁剪成扁平简约形状
- 还原原图的构图与物体位置
- 手工缝纫针迹和轮廓缝线，质朴稚拙的童趣感

**设计流程：**
1. **背景画布**：浅米色粗亚麻画布，背景颜色可根据照片风格轻微调整
2. **拼贴基底**：细长横向窄长方形，高度占画面三分之一
3. **基底边缘**：故意撕扯出毛边并带有松散线头，不完全规整的矩形
4. **材质选择**：格纹棉布、亚麻、水洗粗麻布碎料
5. **裁剪形状**：扁平简约形状，还原原图构图与物体位置

**材质特征：**
- 格纹棉布：温暖的格纹图案
- 亚麻：自然的亚麻质感
- 水洗粗麻布：质朴的粗麻布质感
- 碎料拼贴：手工拼贴感

**缝线特点：**
- 清晰的手工缝纫针迹
- 轮廓缝线
- 扁平质感
- 质朴稚拙
- 交叉缝线

**边缘处理：**
- 故意撕扯出毛边
- 松散线头
- 不规则边缘
- 允许伸出
- 突破基底边缘

**装饰元素：**
- 补丁布片：明显的补丁布片
- 交叉缝线：装饰性缝线
- 碎纸条：层次感
- 线迹文字：细线勾勒缝制的英文小字

**构图规则：**
- 细长横向窄长方形基底
- 高度占画面三分之一
- 景物元素不受拼布基底边框限制
- 允许布片造型向外延伸、探出、突破基底边缘
- 物体可以跨出拼布区域生长延伸

**文字规则：**
- 位置：随机摆放于留白区域
- 内容：与画面内容相关的英文小字
- 样式：字母用细线勾勒缝制，线迹文字
- 尺寸：字体尺寸偏小
- 要求：不遮挡核心景物

**故事感：**
- 手工
- 质朴
- 童趣
- 温暖
- 布艺美学

## 五、数字质感风格

### 像素艺术

**形态参数：**
- 分辨率：低分辨率（如 32x32, 64x64）
- 像素：可见像素方块
- 边缘：锯齿状
- 细节：像素级简化

**质感参数：**
- 方块：清晰像素边界
- 颜色：受限调色板
- 锯齿：边缘特征

**色彩配置：**
- 调色板：8色、16色或自定义
- 无渐变：或用抖动模拟
- 饱和度：通常较高



### 故障老照片

**形态参数：**
- 特征：老照片 + 数字故障混合
- 褪色：棕褐色调
- 故障：RGB分离、撕裂
- 噪点：胶片颗粒 + 数字噪点

**质感参数：**
- 双重质感：物理磨损 + 数字故障
- 撕裂：画面局部撕裂
- 色块：RGB通道错位

**色彩配置：**
- 棕褐色 + RGB偏移
- 褪色 + 异常色彩

## 六、自然质感风格

### 树叶拼贴

**形态参数：**
- 特征：用树叶形状拼贴
- 边缘：叶形轮廓
- 层次：叶片叠加
- 细节：受叶形限制

**质感参数：**
- 叶脉：可见叶脉纹理
- 边缘：枯叶边缘
- 颜色：自然叶色

**色彩配置：**
- 秋叶色：黄、橙、红、褐
- 绿叶色：不同绿色调
- 枯叶色：褐色、灰色

### 光影投影

**形态参数：**
- 特征：光线穿透形成的投影
- 边缘：柔和渐变
- 层次：多重投影叠加
- 细节：受光源影响

**质感参数：**
- 渐变：柔和过渡
- 边缘：模糊边界
- 层次：透明叠加

**色彩配置：**
- 单色光：黑白投影
- 彩色光：RGB投影
- 自然光：暖黄投影
