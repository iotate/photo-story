# 符号记忆

## 核心特征
- 提取照片主体、轮廓、姿态与叙事关系，重构为线性手绘 + 限色专色印刷感的纪念海报
- 等粗 monoline 单线体系，加入克制的轻微抖动、弯曲、错位和不精准转角
- 几何结构线 × 有机手势线，密集线群 × 大面积留白

## 风格DNA
1. **记忆符号化**：用线把记忆符号化，只留下真正决定身份与情绪的少量视觉线索
2. **等粗单线**：monoline 单线体系，线条负责描述形状与结构，不塑造真实体积
3. **开放轮廓**：大量开放轮廓、断续边缘和线条减法，只画到足够识别为止
4. **限色专印**：彩色线条直接承担信息层级，不是黑色描边 + 彩色填充
5. **线密度层级**：重点更密、更深、更集中，背景更疏、更浅、更松
6. **智能留白**：大面积暖白纸面，让空白承担空气、距离、停顿与情绪

## 技术参数

### 色彩参数
- 限色专色体系，从照片中提取最鲜活、最有记忆度的2-4种颜色
- 彩色线条直接承担信息层级
- 主视觉更清晰有力的色线，次级信息更浅更柔和的同系或邻近色
- 色彩编码 + 线条密度 + 明度差建立层次
- 轻微颗粒、套印偏差与不均匀着墨，Risograph/丝网印刷感

### 质感参数
- 等粗 monoline 单线体系
- 克制的轻微抖动、弯曲、错位和不精准转角
- 开放轮廓、断续边缘
- 暖白纸面质感

### 构图特征
- 明确视觉核心
- 依据主体方向、尺度、线条密度和视觉重量进行不对称组织
- 次要元素只在必要位置出现，通过聚散、高低、大小、方向建立阅读路径
- 大面积暖白纸面承担空气、距离、停顿与情绪

## 提示词模板
```
将照片转换为符号记忆风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、姿态与叙事关系。核心不是完整描摹，而是"用线把记忆符号化"：只留下真正决定身份与情绪的少量视觉线索，以最少线条获得最大的识别度，让人物、建筑、植物、动物、器物或环境都像经过记忆筛选后重新被画出来。

【线条体系】
统一采用等粗 monoline 单线体系，线条负责描述形状与结构，不负责塑造真实体积。保持接近一致的线宽，并加入克制的轻微抖动、弯曲、错位和不精准转角，消除机械矢量感；大量使用开放轮廓、断续边缘和线条减法，只画到足够识别为止。外轮廓与内部结构线保持接近的视觉权重，使画面具有旅行图册、地图与建筑图解般的设计气质。

【线条组织】
线条组织根据主体特征智能变化：建筑、器物与结构性对象优先使用横线、竖线、斜线、弧线和几何骨架建立结构性线描；人物、植物、动物与自然形态则使用更柔软的有机曲线与重复线性母题。局部复杂区域不逐项描绘，而通过重复的小线性符号聚合成大形体，并以线密度层级制造前后关系——重点更密、更深、更集中，背景更疏、更浅、更松。整体形成"几何结构线 × 有机手势线、密集线群 × 大面积留白"的双重对比。

【智能留白】
强调智能留白与专业排版。不要平均铺满元素，也不要把每个记忆符号做成同等大小。先确定一个明确视觉核心，再依据主体方向、尺度、线条密度和视觉重量进行不对称组织；次要元素只在必要位置出现，通过聚散、高低、大小、方向和空白建立阅读路径。大面积暖白纸面应主动保留，让空白承担空气、距离、停顿与情绪，使整体像经过精确艺术指导的纪念海报，而不是手绘元素合集。

【限色专印】
配色采用限色专色体系，从上方照片中提取最鲜活、最有记忆度、最能代表主体气质的颜色重新调制，以2-4种彩色线条直接承担信息层级，而不是"黑色描边 + 彩色填充"。主视觉使用更清晰、更有力量的色线，次级信息使用更浅、更柔和的同系或邻近色，通过色彩编码 + 线条密度 + 明度差建立层次。颜色应明亮、干净、温暖而具有生命力，可适度提亮、提纯和去灰；以暖白纸面保持呼吸，并通过轻微颗粒、套印偏差与不均匀着墨形成 Risograph / 丝网印刷般的模拟媒介质感。

【文字融入】
文字少量自由介入，不预设固定标题、地点、日期或语种。可根据照片的身份、关系、动作、记忆、情绪或某个细小线索生成短词、短句或手写注记。字体使用纤细、轻巧、略带书写偏移与不完全规整字距的线性手写字体，与 monoline 图形保持同一种视觉语言；文字可进入大面积留白、沿主体方向、结构轴线或线群边缘错落排布，与图形共同形成阅读节奏，不做传统"标题+正文"的菜单式排版。

【整体气质】
整体呈现暖白纸面、等粗手绘单线、彩色线条编码、限色专印、线密度层级、大面积艺术留白与私人纪念叙事共同构成的高级视觉气质：温暖、亲密、聪明、松弛、略带稚拙，却具有清晰的几何秩序与成熟的编辑设计意识。避免写实素描、粗细变化过大的线条、机械矢量、黑色统一描边、完整背景、元素平均排列、杂乱拼贴、卡通贴纸感和商业模板感。
```
