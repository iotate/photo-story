# 折纸

## 核心特征
- 保留原图最核心的主体、轮廓关系和空间层级
- 将复杂物体概括成少量可实际折叠、裁切、拼接的纸张模块
- 像普通人真的可以用几张纸折出来并摆拍成作品

## 风格DNA
1. **保留核心**：保留原图最核心的主体、轮廓关系和空间层级
2. **概括简化**：不追求细节复刻，将复杂物体概括成少量纸张模块
3. **可折叠性**：造型尽量简单，减少零碎结构与装饰，确保可实际折叠、裁切、拼接
4. **几何折面**：以较大的几何折面、清晰折痕表现
5. **真实手工感**：纸张厚度、切边、自然投影，避免塑料3D、模型感和过度精密结构
6. **明信片排版**：米白或暖白纸张背景，折纸主体缩小并居中，四周充足留白

## 技术参数

### 色彩参数
- 配色：提取原图主色
- 饱和度：适度降低饱和度
- 质感：哑光彩纸
- 纹理：细腻纸纤维纹理

### 质感参数
- 纸张：哑光彩纸质感
- 纤维：细腻纸纤维纹理
- 折痕：清晰可见的折痕
- 厚度：纸张厚度感
- 投影：自然投影效果

### 造型要求
- 较大的几何折面
- 清晰折痕
- 纸张厚度感
- 切边效果
- 自然投影
- 避免零碎结构与装饰
- 避免塑料3D、模型感
- 避免过度精密结构

### 构图特征
- 明信片式排版
- 米白或暖白纸张背景
- 折纸主体缩小并居中
- 四周充足留白
- 所有元素完整收进画面内
- 底部简洁地点名或短标题
- 小型印章元素
