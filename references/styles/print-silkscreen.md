# 丝网印刷

## 核心特征
- 色块平涂、边缘清晰、套色叠加
- 有限色数、鲜艳或做旧
- 均匀色块、略微错位
- 波普艺术、大众文化

## 风格DNA
1. **色块平涂**：均匀、平滑的色块
2. **边缘清晰**：清晰、可能有轻微错位
3. **套色叠加**：可见色块边界
4. **有限色数**：通常3-6色
5. **轻微错位**：轻微位移是特征
6. **网点效果**：无或极细

## 技术参数

### 色彩参数
- 色数：通常3-6色
- 色彩：鲜艳或做旧均可
- 叠加：透明色套印
- 渐变：无或模拟

### 质感参数
- 墨层：均匀、平滑
- 套色：可见色块边界
- 错位：轻微位移是特征
- 网点：无或极细

### 构图特征
- 色块分明
- 边缘清晰
- 套色叠加效果
- 波普艺术感

## 提示词模板
```
将照片转换为丝网印刷风格。保留原图的主体形态，用丝网印刷特有的色块平涂呈现：边缘清晰的色块、套色叠加效果、轻微的位移错位。色彩使用有限色数（3-6色），可以是鲜艳或做旧效果。整体呈现波普艺术感。
```
