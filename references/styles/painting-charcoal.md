# 炭笔画

## 核心特征
- 深黑线条、粗糙质感、强烈对比
- 深黑白灰
- 粗犷笔触、指抹痕迹、颗粒感
- 戏剧性、力量感、艺术家工作室

## 风格DNA
1. **深黑线条**：深黑、粗犷
2. **大面积涂抹**：阴影表现
3. **强烈对比**：强烈黑白对比
4. **颗粒感**：明显炭粉颗粒
5. **指抹痕迹**：模糊边缘
6. **粗糙质感**：画布或粗糙纸面

## 技术参数

### 色彩参数
- 工具：炭笔
- 线条：深黑、粗犷
- 阴影：大面积涂抹
- 对比：强烈黑白对比

### 质感参数
- 颗粒感：明显炭粉颗粒
- 指抹痕迹：模糊边缘
- 粗糙质感：画布或粗糙纸面

### 构图特征
- 强烈明暗对比
- 粗犷笔触
- 戏剧性光影
- 力量感表现

## 提示词模板
```
将照片转换为炭笔画风格。保留原图的主体形态，用炭笔特有的深黑线条和粗犷笔触呈现：强烈的黑白对比、明显的炭粉颗粒感、指抹痕迹带来的模糊边缘。整体呈现戏剧性和力量感。
```
