# 树叶拼贴

## 核心特征
- 用树叶形状拼贴成画面主体
- 自然有机的视觉质感
- 季节感与生命力的表达

## 风格DNA
- 天然树叶的形态与纹理
- 有机的边缘轮廓
- 层叠叠加的空间感
- 自然色彩的和谐组合
- 季节记忆的视觉化
- 生命力的艺术表达

## 技术参数

### 色彩参数
- 秋叶色：黄、橙、红、褐的温暖色调
- 绿叶色：不同层次的绿色调
- 枯叶色：褐色、灰色、米白色
- 饱和度：自然饱和，不人工增强
- 色彩特征：自然、柔和、有季节感

### 质感参数
- 叶脉：可见的自然叶脉纹理
- 边缘：枯叶自然的边缘轮廓
- 表面：叶片的自然质感
- 叠加：叶片重叠的层次感
- 整体：自然、有机、有触感

### 构图特征
- 叶片大小与形状的搭配
- 重叠层次营造空间感
- 色彩渐变与过渡
- 自然留白与密度控制
- 季节氛围的营造

## 提示词模板
```
将照片转换为树叶拼贴风格。

【材料选择】
使用天然树叶进行拼贴创作。根据照片主体选择合适的叶片类型：秋叶表现温暖怀旧，绿叶表现生机活力，枯叶表现沉静内敛。

【形态处理】
保留叶片的自然形态与纹理。叶脉纹理可见，边缘轮廓自然有机。通过叶片的重叠叠加营造空间感与层次感。

【色彩系统】
采用自然的叶片色彩：秋叶的黄、橙、红、褐；绿叶的不同层次；枯叶的褐色、灰色。色彩自然柔和，呈现季节感与生命力。

【构图设计】
叶片大小与形状的合理搭配，重叠层次营造空间感。色彩渐变与过渡自然，留白与密度控制得当。

【整体氛围】
呈现自然、有机、有触感的视觉质感。表达季节记忆与生命力的主题基调。
```
