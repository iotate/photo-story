# 水墨写意

## 核心特征
- 大笔挥洒、墨色浓淡、似与不似之间
- 文人画精神，重神韵轻形似
- 笔墨独立审美价值
- 书画同源

## 风格DNA
1. **大笔挥洒**：笔触可见，墨色浓淡变化
2. **墨分五色**：焦、浓、重、淡、清
3. **计白当黑**：大面积留白，主体占画面30-50%
4. **似与不似**：介于具象与抽象之间
5. **宣纸质感**：墨韵渗透，自然晕化
6. **淡彩点缀**：可有淡彩（花青、赭石、胭脂）

## 技术参数

### 色彩参数
- 主色调：黑白灰，墨分五色（焦、浓、重、淡、清）
- 点缀色：可有淡彩（花青、赭石、胭脂）
- 底色：宣纸白
- 渐变：墨色自然晕化

### 质感参数
- 笔触：大笔挥洒，笔触可见
- 纹理：宣纸肌理，墨韵渗透
- 水分：水墨交融，干湿浓淡
- 留白：大面积留白，计白当黑

### 构图特征
- 以少胜多
- 虚实相生
- 疏密有致
- 黑白对比
- 主体占画面30-50%，留白50-70%

## 提示词模板
```
将照片转换为水墨写意风格。保留原图的主体神韵，用大写意笔法呈现：墨色浓淡变化、笔触挥洒自如、似与不似之间。宣纸质感，大量留白（占画面50-70%），计白当黑，留白与墨韵相得益彰，可有淡彩点缀。整体呈现文人画的禅意与逍遥。
```
