# 水彩画

## 核心特征
- 流动色彩、透明叠加、水渍边缘
- 柔和色彩、透明质感
- 水痕、晕染、纸张纹理
- 梦幻、诗意、转瞬即逝

## 风格DNA
1. **流动色彩**：颜色在湿润的纸上晕染
2. **透明叠加**：透明色层叠加
3. **水渍边缘**：边缘有积水线
4. **纸张纹理**：水彩纸纹理可见
5. **柔和色调**：整体色调柔和
6. **梦幻氛围**：雨后初晴的清新感

## 技术参数

### 色彩参数
- 特性：透明、叠加
- 边缘：水渍痕迹
- 色彩：柔和、渐变
- 透明度：高

### 质感参数
- 水痕：边缘有积水线
- 晕染：颜色自然扩散
- 纸张纹理：水彩纸纹理可见
- 叠加：透明色层叠加

### 技法效果
- 湿画法：边缘模糊、色彩融合
- 干画法：边缘清晰、层叠效果
- 留白：保留纸面白色
- 撒盐：特殊肌理效果

### 构图特征
- 主体位置保留
- 色彩流动
- 水渍边缘
- 柔和过渡

## 提示词模板
```
将照片转换为水彩画风格。保留原图的主体位置和构图，用流动的水彩呈现：颜色在湿润的纸上晕染、边缘有水渍痕迹、透明叠加的层次、纸张纹理清晰可见。整体色调柔和，有种雨后初晴的清新感。
```

- 风景、花卉、柔光场景
