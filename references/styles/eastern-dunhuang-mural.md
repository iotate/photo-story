# 敦煌壁画

## 核心特征
- 基于参考图生成简化壁画风格的印记图像，采用敦煌色彩系统
- 不保留原图照片，只提取主体结构转化为壁画印记
- 不添加额外内容，不添加佛像、飞天、藻井、云纹、花纹等敦煌特有元素

## 风格DNA
1. **敦煌色彩系统**：以矿物颜料为主，色彩庄重典雅
2. **壁画底色**：土黄/赭石色壁画底色
3. **铁线描**：流畅有力的铁线描
4. **矿物颜料**：平涂色块，矿物颜料质感
5. **斑驳质感**：壁画肌理，斑驳、龟裂痕迹
6. **金色点缀**：细节点缀金色

## 技术参数

### 敦煌色彩系统（精确配色）

**核心五色**：
- **焦糖色** `#5e3a1a`：深褐色基调，用于轮廓线、深色区域
- **赭石色** `#8b5e3e`：土红色基调，用于底色、人物肤色
- **土金色** `#c49a50`：暖金基调，用于装饰、高光区域
- **暖金色** `#e0bc70`：明亮金色，用于点缀、细节强调
- **泥金箔** `#f0d898`：最亮金色，用于重要装饰、神圣感

**配色原则**：
- 以焦糖色（#5e3a1a）勾勒轮廓和深色
- 以赭石色（#8b5e3e）作为底色和过渡
- 以土金色（#c49a50）、暖金色（#e0bc70）平涂主体
- 以泥金箔（#f0d898）点缀细节和装饰

**对比关系**：
- 焦糖（深）与泥金箔（亮）形成强烈对比
- 赭石与土金形成温暖过渡
- 整体色调温暖庄重，有西域风情

### 质感参数
- 壁画肌理：斑驳、龟裂痕迹
- 矿物颜料：厚实感
- 线条：铁线描，流畅有力

### 构图特征
- 主体简化为可识别轮廓
- 平涂色块
- 流畅有力的铁线描
