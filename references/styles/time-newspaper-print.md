# 报纸印刷

## 核心特征
- 报纸印刷的点阵效果
- 黑白或单色、半色调网点
- 粗糙网点、新闻纸纹理
- 历史记录、大众记忆

## 风格DNA
1. **半色调网点**：可见网点图案
2. **新闻纸质感**：粗糙纸面
3. **油墨不均**：随机深浅变化
4. **单色印刷**：黑白或单色
5. **网点密度**：根据明暗变化
6. **历史感**：大众记忆载体

## 技术参数

### 色彩参数
- 模式：黑白或单色
- 半色调：可见网点图案
- 网点密度：根据明暗变化

### 质感参数
- 网点图案：圆形或菱形网点
- 纸张纹理：新闻纸粗糙感
- 油墨不均：随机深浅变化

### 构图特征
- 保留原图主体
- 印刷网点点阵
- 新闻排版感

## 提示词模板
```
将照片转换为报纸印刷风格。呈现报纸印刷的点阵效果：黑白或单色，可见的半色调网点图案，新闻纸的粗糙质感，油墨随机深浅变化。整体呈现历史记录、大众记忆的感觉。
```
