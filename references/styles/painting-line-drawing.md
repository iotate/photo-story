# 白描画

## 核心特征
- 简洁线条、大量留白、无阴影
- 单色墨线勾勒轮廓
- 流畅线条、轻重变化、宣纸底纹
- 东方、禅意、留白之美

## 风格DNA
1. **简洁线条**：最简洁的线条勾勒轮廓
2. **无阴影无色彩**：无阴影、无色彩、大量留白
3. **书法韵味**：线条有书法般的韵味，轻重顿挫
4. **宣纸质感**：宣纸般质感的底面
5. **大量留白**：留白作为构图的重要组成部分
6. **东方美学**：东方、禅意、留白之美

## 技术参数

### 色彩参数
- 单色墨线（黑色或深褐色）
- 无色彩、无阴影
- 宣纸白色底

### 质感参数
- 工具：毛笔/墨线
- 线条：单色墨线
- 特征：无阴影、无色彩、大量留白
- 韵律：书法般的轻重顿挫
- 底面：宣纸质感
- 留白：占据画面大部分
- 线条：简洁但有韵味
- 转折：有力、不犹豫

### 构图特征
- 线条简洁但有韵味
- 大量留白
- 主体居中或偏置
- 无背景细节

## 提示词模板
```
将照片转换为传统白描风格。保留原图的主体外形和空间关系，用最简洁的线条勾勒轮廓：无阴影、无色彩、大量留白。线条有书法般的韵味，轻重顿挫，在宣纸般质感的底面上呈现。
```
