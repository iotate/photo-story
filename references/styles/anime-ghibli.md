# 吉卜力风格

## 核心特征
- 手绘质感、水彩背景、柔和线条、自然光影
- 以宫崎骏作品为代表的经典动画风格
- 人与自然和谐的主题表达
- 温暖治愈的情感基调

## 风格DNA
1. **手绘质感**：手绘笔触可见但不粗糙
2. **水彩背景**：水彩质感、层次丰富
3. **柔和线条**：柔和、有温度感
4. **纸张质感**：轻微纸张质感
5. **自然光影**：温暖的光影效果
6. **治愈氛围**：人与自然和谐

## 技术参数

### 色彩参数
- 主色调：温暖饱和的自然色调
- 典型色：天空蓝、草地绿、泥土褐、云白
- 饱和度：中等偏高，温暖感
- 对比度：中等，柔和

### 质感参数
- 笔触：手绘笔触可见但不粗糙
- 背景：水彩质感、层次丰富
- 线条：柔和、有温度感
- 纸张：轻微纸张质感

### 构图特征
- 广角远景常见
- 天空占据重要位置
- 自然元素丰富
- 留白得当

## 提示词模板
```
将照片转换为吉卜力风格。保留原图的主体形态和构图，用手绘质感、水彩背景、柔和线条呈现：温暖的色彩、自然的光影、有温度感的线条。整体呈现人与自然和谐的温暖治愈氛围。
```

## 适用场景
- 风景、人物、自然场景、治愈主题
