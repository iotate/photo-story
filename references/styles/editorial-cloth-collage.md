# 布艺拼贴

## 核心特征
- 用格纹棉布、亚麻和水洗粗麻布碎料裁剪成扁平简约形状
- 还原原图的构图与物体位置
- 手工缝纫针迹和轮廓缝线，质朴稚拙的童趣感

## 风格DNA
1. **背景画布**：浅米色粗亚麻画布，背景颜色可根据照片风格轻微调整
2. **拼贴基底**：细长横向窄长方形，高度占画面三分之一
3. **基底边缘**：故意撕扯出毛边并带有松散线头，不完全规整的矩形
4. **材质选择**：格纹棉布、亚麻、水洗粗麻布碎料
5. **裁剪形状**：扁平简约形状，还原原图构图与物体位置
6. **边缘处理**：可以有一些不规则的边缘/伸出

## 技术参数

### 色彩参数
- 浅米色粗亚麻画布背景
- 格纹棉布、亚麻、水洗粗麻布碎料的自然色彩
- 可根据照片风格轻微调整背景颜色

### 质感参数
- 格纹棉布：温暖的格纹图案
- 亚麻：自然的亚麻质感
- 水洗粗麻布：质朴的粗麻布质感
- 碎料拼贴：手工拼贴感

### 缝线特点
- 清晰的手工缝纫针迹
- 轮廓缝线
- 扁平质感
- 质朴稚拙
- 交叉缝线

### 边缘处理
- 故意撕扯出毛边
- 松散线头
- 不规则边缘
- 允许伸出
- 突破基底边缘

### 装饰元素
- 补丁布片：明显的补丁布片
- 交叉缝线：装饰性缝线
- 碎纸条：层次感
- 线迹文字：细线勾勒缝制的英文小字

### 构图规则
- 细长横向窄长方形基底
- 高度占画面三分之一
- 景物元素不受拼布基底边框限制
- 允许布片造型向外延伸、探出、突破基底边缘
- 物体可以跨出拼布区域生长延伸

## 提示词模板
```
将照片转换为布艺拼贴风格。整张背景为浅米色粗亚麻画布，背景颜色可以根据照片的风格颜色做轻微调整。画面中央放置一块细长横向窄长方形布艺拼贴基底，高度占画面的三分之一，基底轮廓不要做成完全规整的矩形，边缘故意撕扯出毛边并带有松散线头。用格纹棉布、亚麻和水洗粗麻布碎料裁剪成扁平简约形状，还原原图的构图与物体位置，可以有一些不规则的边缘/伸出。每条轮廓线都可见清晰的手工缝纫针迹和轮廓缝线，带有扁平、质朴稚拙的童趣感，增加明显的补丁布片、交叉缝线和碎纸条层次。画面里的景物元素不受拼布基底边框限制，允许布片造型向外延伸、探出、突破基底边缘，物体可以跨出拼布区域生长延伸。在拼贴画的空白处加入一句与画面内容相关的英文小字，字母用细线勾勒缝制，属于线迹文字，和整体拼布风格匹配，字体尺寸偏小，位置随机摆放于留白区域，不要遮挡核心景物。
```
