# 写实电影

## 核心特征
- 保持原构图与主题位置不变
- 根据画面情况设计布光逻辑、色彩调性、镜头质感
- 三大核心：布光逻辑 + 色彩调性 + 镜头质感

## 风格DNA
1. **布光逻辑**：黄金时刻逆光、蓝调时刻微光、伦勃朗光、侧漫射柔光、窗光/缝隙丁达尔、低光氛围感夜景
2. **色彩调性**：复古暖胶片、冷调蓝青电影感、莫兰迪低饱和、浓烈对比色
3. **镜头质感**：焦段与景深、胶片颗粒、暗角、宽容度、画幅比例
4. **叙事感**：电影开场、瞬间定格

## 技术参数

### 色彩参数
**色彩调性方案（成套搭配，一组只选一套）：**

1. **复古暖胶片（文艺叙事）**
   - 低饱和暖棕、焦糖色、赭石、柔和橘色
   - 冷蓝阴影，色彩对比度适中
   - 适用：怀旧、记忆、温暖叙事

2. **冷调蓝青电影感（悬疑/孤寂/夜景）**
   - 主色调冷青灰、雾霾蓝
   - 少量暖橙色光源作为对比色点缀
   - 适用：悬疑、孤独、城市夜景

3. **莫兰迪低饱和（安静治愈）**
   - 灰度偏高，柔和灰绿、灰米、淡赭石
   - 色彩淡雅，几乎没有高饱和亮色
   - 适用：安静、治愈、日常生活

4. **浓烈对比色（史诗、戏剧性画面）**
   - 主色深蓝，高光暖金
   - 明暗色彩分离，阴影冷色，亮部暖色
   - 适用：史诗、戏剧性、大片感

### 质感参数
**焦段与景深：**
- 广角（16-35mm）：大场景、环境叙事、畸变张力
- 标准（35-50mm）：自然视角、人文纪实
- 长焦（85-135mm）：压缩空间、主体突出、浅景深

**胶片颗粒：**
- 细腻颗粒：现代数字电影感
- 粗颗粒：复古胶片质感、年代感

**暗角：**
- 轻微暗角：聚焦视觉中心
- 明显暗角：复古胶片、氛围感

**画幅比例：**
- 16:9 或 2.35:1（电影宽银幕）
- 4:3 或 1.33:1（复古胶片）

### 构图特征
- 保持原图构图与主体位置不变
- 光影、色彩、镜头三者协调统一

## 提示词模板
```
将照片转换为写实电影风格。

【画面分析】
分析原图场景类型（室内/室外/夜景/日景）、主体（人物/建筑/风景）、氛围需求（温暖/冷清/戏剧/安静），据此设计光影、色彩、镜头方案。

【光线设计】
根据场景选择1-2种光线类型：
- 黄金时刻逆光：轮廓光，柔和金边光晕，光线穿过薄雾形成光束
- 蓝调时刻微光：冷弱环境光，局部暖光源对比
- 伦勃朗光：单侧硬光，面部/主体形成三角光斑，明暗对比强烈
- 侧漫射柔光：阴天散射光，柔和过渡，阴影细腻无锐利边界
- 窗光/缝隙丁达尔：空气中悬浮微粒，可见光束，光斑散景
- 低光氛围感夜景：大面积深邃暗部，少量高光点缀，暗部保留细节

【色彩调性】
选择一套色彩方案（一组只选一套）：
- 复古暖胶片：低饱和暖棕、焦糖色、赭石、柔和橘色，冷蓝阴影
- 冷调蓝青电影感：主色调冷青灰、雾霾蓝，少量暖橙色光源对比
- 莫兰迪低饱和：灰度偏高，柔和灰绿、灰米、淡赭石，色彩淡雅
- 浓烈对比色：主色深蓝，高光暖金，阴影冷色，亮部暖色

【镜头质感】
设定焦段、景深、胶片颗粒、暗角、宽容度、画幅比例：
- 焦段：根据场景选择广角/标准/长焦
- 景深：根据叙事需求选择深景深/浅景深
- 颗粒：细腻颗粒（现代感）或粗颗粒（复古感）
- 暗角：轻微（聚焦中心）或明显（氛围感）
- 宽容度：高（保留细节）或低（戏剧对比）
- 画幅：16:9 或 2.35:1（电影宽银幕），或 4:3（复古胶片）

【光影细节】
确定光源方向、软硬、明暗反差、氛围光斑/薄雾、暗部层次（不要死黑）。保持原图构图与主体位置不变。

【整体效果】
呈现电影开场镜头质感，瞬间定格的叙事感，光影、色彩、镜头三者协调统一。
```

## 适用场景
- 街景、建筑、人物、日常生活场景

## 反模式
- 过度调色
- 不协调的色彩搭配
- 失去原图主体位置
- 光影不统一

## 故事感
- 电影开场
- 叙事感
- 瞬间定格
