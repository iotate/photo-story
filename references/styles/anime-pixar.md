# 皮克斯风格

## 核心特征
- 3D质感、夸张造型、生动表情、温暖光影
- 以《玩具总动员》《寻梦环游记》等作品为代表
- 技术与情感的结合，家庭与成长的主题

## 风格DNA
- 顶级3D渲染技术
- 夸张生动的角色造型
- 专业电影级灯光设计
- 温暖友好的色彩基调
- 情感驱动的故事表达
- 技术与艺术的完美平衡

## 技术参数

### 色彩参数
- 主色调：明亮饱和、温暖友好
- 典型色：温暖黄、友好蓝、活力橙、信任绿
- 饱和度：高饱和，明快活泼
- 对比度：中等，温馨舒适
- 色彩特征：温暖、明亮、友好

### 质感参数
- 渲染：顶级3D渲染
- 材质：真实质感与艺术化处理
- 灯光：专业电影级灯光设计
- 表情：夸张生动的表情表现
- 质感特征：精致、立体、有温度

### 构图特征
- 动态感强的画面构图
- 角色表现突出
- 环境丰富多彩
- 镜头语言专业
- 空间层次分明

## 提示词模板
```
将照片转换为皮克斯风格。

【3D渲染】
采用顶级3D渲染技术，呈现精致的立体质感。材质真实而有艺术感，灯光专业而有温度。

【角色造型】
夸张生动的角色造型，表情丰富而富有感染力。保持原图主体的核心特征，进行艺术化夸张处理。

【色彩系统】
使用明亮饱和的色彩：温暖黄、友好蓝、活力橙、信任绿。色彩温暖友好，呈现积极向上的氛围。

【灯光设计】
专业电影级灯光设计，营造温暖、有层次的光影效果。灯光服务于情感表达和故事叙事。

【整体氛围】
呈现家庭亲情、成长冒险、温暖励志、友谊与爱的主题基调。视觉精致、生动、富有感染力。
```

## 适用场景
- 人物肖像：家庭主题、儿童、角色设计
- 动物主题：宠物、动物角色、拟人化表现
- 场景设计：室内、城市、自然场景
- 情感叙事：家庭、友谊、成长主题

## 反模式
- 低饱和的暗淡色彩
- 平面化的视觉处理
- 缺乏表情的僵硬造型
- 冷硬的灯光效果

## 故事感
- 家庭亲情
- 成长冒险
- 温暖励志
- 友谊与爱
