# 儿童绘本

## 核心特征
- 温暖儿童绘本手绘插画
- 柔和平涂色彩，清晰轮廓线条
- 简约卡通造型，可爱松弛画风
- 严格继承原图主体动作、构图、姿态、相对位置

## 风格DNA
1. **保留核心**：主体动作、构图、姿态、相对位置严格继承原图
2. **手绘质感**：绘本手绘风格，柔和平涂色彩，清晰轮廓线条
3. **卡通造型**：简约卡通造型，可爱松弛画风，不追求写实
4. **色彩搭配**：干净明快配色，柔和温暖色调
5. **背景简化**：简化背景环境元素，保留场景特征
6. **文字可选**：默认无文字，用户要求时可添加少量简短文字

## 技术参数

### 色彩参数
- 主色调：柔和温暖色调
- 配色原则：干净明快，不超过4-5种主色
- 平涂技法：柔和均匀的平涂色彩
- 轮廓线：清晰的深色轮廓线

### 质感参数
- 绘本手绘风格
- 柔和平涂色彩
- 清晰轮廓线条
- 简约卡通造型

### 主体处理规则
- 人物：保持原图姿态和互动关系，简化为可爱卡通造型，清晰轮廓线
- 动物：保持原图动作和相对位置，圆润可爱造型，柔和色彩
- 场景：简化背景元素，保留关键场景特征，温暖色调
- 互动关系：严格保持角色互动关系，不新增删减主要对象

### 构图特征
- 继承原图构图
- 简化背景
- 主体清晰
- 可爱造型

## 提示词模板
```
将照片转换为儿童绘本风格。

【保留核心】
严格继承原图主体动作、构图、人物/动物姿态、相对位置。不改变角色互动关系，不新增删减主要对象。

【手绘质感】
绘本手绘风格，柔和平涂色彩，清晰轮廓线条，简约卡通造型，可爱松弛画风。

【色彩搭配】
干净明快配色，柔和温暖色调，不超过4-5种主色。使用柔和平涂技法。

【背景处理】
简化背景环境元素，保留场景特征，不喧宾夺主。

【文字元素】
默认不添加文字。仅在用户明确要求时，才在画面下半部分添加少量简短绘本风格文字，文字贴合画面情景，可爱圆润字体，不遮挡主体。

【整体效果】
像儿童图画书内页，印刷绘本质感，无写实照片。
```

## 适用场景
- 人物、动物、生活场景、温馨主题

## 反模式
- 改变原图主体数量、动作姿态、物体位置、构图关系
- 新增或删减主要对象
- 改变角色互动关系
- 写实照片质感
- 复杂背景抢夺主体注意力
- 默认情况下添加文字（除非用户要求）
