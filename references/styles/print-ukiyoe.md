# 浮世绘

## 核心特征
- 平面装饰、轮廓线、木版纹理
- 传统日本配色、矿物颜料
- 木版压印痕迹、纸张纹理
- 东方古典、装饰美学

## 风格DNA
1. **轮廓线明确**：流畅、有韵律
2. **平面装饰**：平面装饰性强
3. **非西方透视**：非西方透视
4. **木版纹理**：压印纹理
5. **传统配色**：靛蓝、朱红、赭石、淡黄
6. **和纸质感**：纸张纹理

## 技术参数

### 色彩参数
- 传统色：靛蓝、朱红、赭石、淡黄
- 配色：和谐、装饰性
- 渐变：少或用版画技法
- 矿物颜料质感

### 质感参数
- 木版：压印纹理
- 纸张：和纸质感
- 颜料：矿物颜料质感
- 云纹：传统图案

### 构图特征
- 轮廓线明确
- 平面装饰性强
- 非西方透视
- 传统图案元素

## 提示词模板
```
将照片转换为浮世绘风格。保留原图的主体形态，用浮世绘特有的平面装饰和流畅轮廓线呈现：明确的轮廓线、木版压印纹理、和纸质感。色彩使用传统的靛蓝、朱红、赭石、淡黄，整体呈现东方古典装饰美学。
```
