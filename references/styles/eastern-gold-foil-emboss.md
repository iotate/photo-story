# 金箔压纸

## 核心特征
- 提取照片主体、轮廓、结构、姿态与叙事关系
- 重新概括为精致、克制的线性图形
- 暖米白棉质艺术纸 + Blind Deboss深压印 + Champagne Gold Foil
- 向内凹陷的物理触感

## 风格DNA
1. **纤细描线**：类似高端botanical illustration的纤细描线、简化轮廓与少量结构细节
2. **深压印工艺**：Blind Deboss/Letterpress深压印，金色线条位于真实凹槽内部
3. **香槟金箔**：柔和的香槟金箔，与纸张一起被深压进入纸面
4. **向内凹陷**：四周形成细微的纸张挤压、边缘高光和自然阴影
5. **纸张质感**：暖米白棉质艺术纸，可见纸张纤维
6. **极简平衡**：极简、平衡、留白充足，主体作为唯一视觉核心

## 技术参数

### 色彩参数
- 暖米白纸张底色
- 香槟金箔主体图形
- 少量无墨blind deboss作为第二层结构
- 色彩极度克制：纸张色 + 金色

### 质感参数
- 暖米白棉质艺术纸，可见纸张纤维
- Blind Deboss/Letterpress深压印
- 柔和的香槟金箔，向内凹陷
- 细微的纸张挤压、边缘高光和自然阴影
- 双层结构：金色凹压 + 少量无墨blind deboss形成细腻深浅关系

### 构图特征
- 极简、平衡、留白充足
- 主体作为唯一视觉核心
- 可居中或根据原图轮廓进行轻微偏移
- 以尺度、正负形和细线走势建立优雅秩序

## 提示词模板
```
将照片转换为金箔压纸风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、结构、姿态与叙事关系，只保留最关键的身份特征，将其重新概括为精致、克制的线性图形。无论原图是建筑、人物、动物、植物、器物、交通工具或自然景观，都以类似高端botanical illustration的纤细描线、简化轮廓与少量结构细节重新组织，让人一眼认出原物，但不做写实描摹和复杂插画。

【材质工艺】
材质采用暖米白棉质艺术纸 + Blind Deboss/Letterpress深压印 + Champagne Gold Foil。主体图形本身统一使用柔和的香槟金箔，并与纸张一起被深压进入纸面：金色线条位于真实凹槽内部，四周形成细微的纸张挤压、边缘高光和自然阴影，强调"向内凹陷"的物理触感，而不是凸起浮雕或表面贴金。局部可保留少量无墨blind deboss作为更低调的第二层结构，与金色凹压形成细腻深浅关系。

【构图设计】
构图保持极简、平衡、留白充足，主体作为唯一视觉核心，可居中或根据原图轮廓进行轻微偏移，以尺度、正负形和细线走势建立优雅秩序。不要加入多余装饰；若原图自身具有植物、波纹、建筑曲线、轨迹或其他具有美感的结构，可将其简化为极少量金色细线，与主体自然延展形成完整标识式构图。

【文字融入】
文字少量介入，根据照片的主体、地点、情绪或象征意义自由提炼简短标题或微型注释，不固定语种和信息格式。字体使用纤细、优雅、略带古典雕刻韵味但保持现代比例的编辑字体，同样采用香槟金箔深压工艺，与主体图形共同压入纸面，使图文像一次完成的高级印刷工艺，而不是后期叠加的文字。

【整体气质】
整体呈现暖米白棉质艺术纸、深压印、凹陷香槟金箔、纤细描线、可见纸张纤维、细微边缘高光和压印阴影共同形成的低调奢华气质，像高端香氛、花艺、珠宝、婚礼纸品与精品品牌视觉系统。强调真实纸张纤维、压痕深度、金箔细微反光与安静留白，避免凸起烫金、亮黄色金属、镜面金、金属渐变、塑料浮雕、3D渲染、复杂彩色插画、过度装饰和模板感。
```
