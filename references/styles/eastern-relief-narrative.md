# 浮雕叙事

## 核心特征
- 提取照片主体、轮廓、姿态与叙事关系
- 重构为中国印压浮雕/纸雕凹凸质感的极简艺术海报
- 浅浮雕、细腻阴影、极简线刻、克制层次

## 风格DNA
1. **主体提取**：提取最具识别性的主体、轮廓、姿态与叙事关系
2. **浮雕重构**：中国印压浮雕/纸雕凹凸质感，浅浮雕、细腻阴影
3. **色彩克制**：乳白、暖白、浅纸色为主，同色系浅浮雕，少量哑金色点缀
4. **构图秩序**：俯瞰/正视/微俯视/轴线延展，清晰主次、纵深秩序
5. **文字融合**：文字成为画面结构的一部分，非后期贴上的信息层
6. **博物馆感**：宁静、高级、克制、展览海报气质

## 技术参数

### 色彩参数
- 基底色：乳白、暖白、浅纸色大面积留白
- 主体色：同色系浅浮雕，通过光影建立层次
- 点缀色：哑金色细节（仅用于关键局部）
- 光感：柔和暖白光感（仅用于视觉焦点）

### 质感参数
- 压印在厚重乳白色纸张上
- 浅浮雕、细腻阴影
- 极简线刻、克制层次
- 纸张雕塑感

### 构图特征
- 俯瞰构图：适合建筑群、场景整体、平面化叙事
- 正视构图：适合人物肖像、器物、正面主体
- 微俯视构图：适合动物、植物、有体积感的主体
- 轴线延展：适合街道、桥梁、有纵深的空间

## 提示词模板
```
将照片转换为浮雕叙事风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、姿态与叙事关系。不机械复刻细节，保留最核心的结构特征与空间关系，使人一眼能够识别与上方为同一对象。

【浮雕重构】
重构为中国印压浮雕/纸雕凹凸质感的极简艺术海报。整体像压印在厚重乳白色纸张上，以浅浮雕、细腻阴影、极简线刻和克制层次重新概括主体。

【构图设计】
根据主体类型，转化为俯瞰/正视/微俯视/轴线延展的浅浮雕构图。适度保留与主体相关的环境轮廓，使画面具有清晰主次、纵深秩序与博物馆展陈般的宁静感。

【色彩系统】
整体以乳白、暖白或浅纸色大面积留白为基底，主体及相关元素统一以同色系浅浮雕呈现。通过压印高低差、边缘投影和细微明暗建立层次。仅在主体最关键的局部结构或视觉焦点处加入少量哑金色细节与柔和暖白光感，强化核心识别点，避免颜色杂乱和过度装饰。

【文字融合】
文字转化为画面结构的一部分。从照片的主体身份、地点属性、主题气质、动作状态或象征意义中提炼简短文字：标题 + 关键词 + 少量编号/地点/微型注释/哲理金句。采用克制的金色或深灰色衬线/高级编辑字体，置于中央轴线、主体下方、留白边缘或与浮雕结构对齐，使其与压印主体共同形成秩序感与展览海报气质。

【整体气质】
高级、宁静、极简、克制、东方美学、博物馆海报感与纸张雕塑感。避免文字乱码、低清晰度、主体畸形、颜色杂乱、构图拥挤、廉价3D感和模板感。
```
