# 新海诚风格

## 核心特征
- 超写实背景、绚烂天空、镜头光晕、强烈光影
- 以《你的名字》等作品为代表的经典动画风格
- 极致的光影美学与青春情感的视觉化表达

## 风格DNA
- 超写实精细渲染的背景画面
- 绚烂的天空色彩与云层表现
- 镜头光晕与逆光效果的极致运用
- 强烈的色彩对比与光影戏剧性
- 青春情感的视觉化氛围营造
- 细腻而富有诗意的镜头语言

## 技术参数

### 色彩参数
- 主色调：高饱和的天空色彩
- 典型色：天空蓝紫、晚霞橙红、樱花粉、新绿
- 饱和度：高饱和，鲜艳明亮
- 对比度：高对比，光影强烈
- 色彩特征：极致绚烂的自然色彩

### 质感参数
- 渲染：超精细渲染
- 光线：镜头光晕、逆光、丁达尔效应
- 质感：照片级真实感与动画美学的结合
- 细节：极致精细的背景细节
- 光影：强烈而富有戏剧性

### 构图特征
- 天空占据画面大比例
- 强烈的透视感与纵深感
- 光影主导构图节奏
- 镜头语言丰富多变
- 远景与特写的对比运用

## 提示词模板
```
将照片转换为新海诚风格。

【光线设计】
采用极致的光影美学：绚烂的天空色彩、镜头光晕、逆光效果、丁达尔效应。光线是画面的核心叙事元素。

【色彩系统】
使用高饱和的天空色彩：天空蓝紫、晚霞橙红、樱花粉、新绿。色彩绚烂而富有诗意，营造青春情感的氛围。

【背景渲染】
超精细渲染的背景画面，照片级真实感与动画美学的完美结合。细节极致精细，特别是天空、云层、城市景观等元素。

【构图特征】
天空占据重要位置，强烈的透视感，光影主导构图。运用丰富的镜头语言，创造富有戏剧性的画面张力。

【整体氛围】
呈现青春思念、距离等待、唯美瞬间、命运交织的情感基调。光影、色彩、细节三者协调统一，创造极致的视觉美学。
```

## 适用场景
- 城市景观：城市街道、车站、天桥、都市夜景
- 自然风景：天空、云层、日落、樱花、田野
- 人物肖像：青春主题、情感叙事、逆光人像
- 建筑空间：学校、车站、城市建筑

## 反模式
- 低饱和度的暗淡色彩
- 缺乏光影层次的平面效果
- 粗糙简单的背景处理
- 缺乏情感氛围的画面

## 故事感
- 青春思念
- 距离等待
- 唯美瞬间
- 命运交织
