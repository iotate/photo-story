# 风格转换技术细节参考

本文件提供各种风格的技术参数和转换细节，确保风格化转换的质量和一致性。

## 核心原则

### 结构保留清单

在所有风格转换中必须保留：

1. **主体位置**：主要元素在画面中的相对位置不变
2. **大小比例**：元素之间的大小关系不变
3. **构图框架**：三分、对称、中心等构图结构不变
4. **空间层次**：前景、中景、背景的关系不变
5. **轮廓识别**：主体的外形能够被识别

### 风格转换清单

在风格转换中必须改变：

1. **色彩系统**：色调、饱和度、对比度根据风格调整
2. **质感细节**：纹理、颗粒、笔触根据风格添加
3. **线条处理**：清晰度、风格化程度根据风格调整
4. **边缘处理**：锐利、柔和、风格化边缘

## 一、东方故事风格（默认）

### 东方故事

**核心特征：**
- **基于参考图生成简化版画风格的印记图像**
- 不保留原图照片，只提取主体结构转化为版画印记
- 暖象牙白/米白色纸张底色
- **保留原图特征性色彩，调整为东方美学色调**
- 现代版画语言 + 东方克制美学

**关键区别（避免误读）：**
- ❌ 不是整张照片做旧、泛黄或上色
- ❌ 不是银盐相纸、手工上色、复古摄影
- ❌ 不是纯黑白或深墨色印记
- ✅ 是完全重新生成的版画风格图像，保留特征性色彩

**结构参数：**
- 布局：竖版图像，单一画面
- 底色：暖象牙白 #F5F0E6、米白色 #FAF8F5、或安静的源光色调
- 整体：纸张质感的平面，承载简化的主体印记

**色彩参数：**
- 底色：暖象牙白、米白色
- **特征性色彩**：保留原图的主要色彩，调整为东方美学色调
  - 红色系 → 朱砂红 #C53030、胭脂红
  - 蓝色系 → 石青蓝 #1A365D、靛蓝
  - 黄色系 → 藤黄 #D69E2E、赭石褐
  - 绿色系 → 石绿、青碧
  - 紫色系 → 紫檀、青莲
- **禁止**：泛黄、做旧、复古色调、完全黑白化

**质感参数：**
- 画面质感：干净纸张质感，轻微纹理，不喧闹
- 印记风格：现代版画语言
  - 平涂色块（solid color blocks）
  - 柔化边缘（softened edges）
  - 负空间切割（negative-space cuts）
  - 稀疏线条（sparse lines）
  - 有节制的断点（measured breaks）
- 留白：大量留白，印记不填满画面
- **禁止**：厚重纹理、粗糙颗粒、仿旧效果

**印记语法：**
- 主要形态：一个清晰可识别的主体印记（占画面宽度 35-55%）
- 辅助印记：极少量支持性印记
  - 基座线条
  - 地平线/地面
  - 比例标记（人物用小垂直刻痕）
- 细节转换规则：
  - 屋顶层次 → 2-4 条堆叠弧线，保留原有色彩
  - 窗户 → 3-5 个稀疏小点或短切口
  - 人物 → 3-8 个小垂直刻痕（无脸、无细节）
  - 水面 → 1-2 条水平残留线
  - 天空/光 → 保留为纸张留白，或用淡雅色彩暗示
- **禁止**：复杂细节、装饰性元素、写实描绘

**风格参照：**
- 现代平面设计中的极简版画
- 东方美学的留白与克制
- 传统中国画色彩体系
- 编辑设计中的系列艺术海报
- **不是**：复古摄影、手工上色、银盐工艺、纯黑白版画

**故事感：**
- 东方美学的诗意化呈现
- 安静、克制、有呼吸感
- 可重复的系列识别度
- 画廊标签般的诗意（可选小标题）

**适用场景：**
- 建筑、地标、天际线、桥梁
- 有清楚轮廓、强光影的场景
- 旅行、城市、自然景观
- 适合制作系列艺术作品

**提示词示例：**
```
基于参考图生成东方故事风格图像。

画面要求：
- 竖版图像，暖象牙白或米白色纸张底色
- 使用现代版画语言呈现简化的主体
- 大量留白，主体占画面宽度 35-55%

色彩处理：
- 保留原图的特征性色彩
- 调整为东方美学色调（朱砂红、石青蓝、赭石褐、藤黄等）
- 色彩简洁、雅致，不喧闹

印记风格：
- 平涂色块，保留特征性色彩
- 柔化边缘，不锐利
- 负空间切割，留白充分
- 稀疏线条，细节极少

风格禁止：
- 禁止泛黄、做旧、复古摄影风格
- 禁止银盐相纸、手工上色
- 禁止厚重纹理、粗糙颗粒
- 禁止完全黑白化、失去特征性色彩
- 禁止复杂细节、装饰元素

整体呈现：东方美学意境、诗意化色彩、留白之美。
```

**变体配方：**

印记语法：
- 墨章建筑：块状形态 + 负空间切割 + 特征性色彩
- 堆叠秩序：弧线、条带、台阶简化为 3-5 个层次，保留色彩
- 天际线记忆：地标主形态 + 2-3 辅助条 + 地平线
- 光影遗珍：主体剪影轻压入柔和光场，保留淡雅色彩
- 边缘残留：4-6 条果断边缘聚集成可识别图案

色彩重量：
- 雅致色块：保留特征性色彩，调整为东方美学色调（默认）
- 淡彩：色彩更淡雅、含蓄
- 重彩：色彩更浓郁、有力量
- 单色：仅用一种特征色 + 纸张底色

## 四、编辑设计风格

### 扁平海报风格

**核心特征：**
- 朴素民间艺术印刷语言，平静、密集、扁平的海报
- **保留原图的内容布局和主体结构**，仅转换视觉风格
- 不删除或新增原图中没有的主要元素

**五大标志性原则：**
1. **世界是平摊的**：地面呈现为从上方观看的倾斜地图式色块，而树木、人物、建筑、车辆以扁平立面直立呈现。无消失点，无汇聚线，无3D效果。
2. **密纹成静**：平静来自密集、均匀、手工的质感——而非空白极简。抽象通过微缩实现，而非删减。
3. **色窄成静**：每幅图像使用纸白、暖墨黑，以及仅2-4种克制的、墨感的区域色。密集的场域保持安静，因为颜色保持稀少而柔和。
4. **一枚亮色**：每幅图像恰好使用一种饱和色——任意色相，是全图唯一的高饱和色，且总是承担构图任务（焦点物体或结构线颜色）。
5. **人是刻度**：微小的无面人物做着日常事务，赋予场景尺度、节奏和温度。

**透视规则（硬性约束）：**
- 地面区域从上方观看，扁平如手绘地图
- 树木、人物、建筑、车辆以简单的扁平立面（侧面或正面视图）直立在这些区域上，如儿童画或民间地图
- 无消失点、无汇聚线、无透视缩短、无地平线大气
- 距离仅可通过轻微的尺寸缩小和在画布上较高的位置来表现
- 无物投下阴影。光线均匀且无方向

**质感语法：**
每个颜色区域恰好承载一种质感系统，在该区域内节奏和密度均匀：
- **窗户点阵**：用于建筑群的小矩形/点状窗户阵列；每个立面是略微不同的手绘网格
- **缝线虚线**：用于水面、草地、铺装的短平行虚线或手工刻痕；方向跟随区域的流动
- **编织丝网颗粒**：一种整体织物般的丝网印刷颗粒，可覆盖整幅图像
- **树冠涂鸦块**：用于树冠的密集环状/刻痕块——树冠是填充的深色块，绝非仅线条的叶丛或骨架轮廓；树干是单根自信的线条
- **纯墨轮廓**：用于人物、车辆、长椅、道具的干净抖动手绘线；最少的内部细节

**质感规则：**
- 绝不在一个区域内混合两种质感系统
- 绝不让质感密度在区域内漂移
- 质感是手工的，笔触略有不规则，但整体节奏均匀
- 所有质感是纸上的不透明平涂墨色：无渐变、无透明度坡度、无绘画式融合

**色彩系统：**

固定锚点（每幅图像）：
- **纸白**：带有可见颗粒的暖色米白纸；也可用作区域色（天空、散步道、雪、沙）
- **墨黑**：用于所有轮廓、人物、窗户网格和深色区域的暖近黑色

区域色彩（每幅图像全新选择）：
- 从场景推导：季节、时间、气候、材料
- 保持每种区域色低至中等饱和度，墨感，印刷感
- 典型色域：深瓶绿、鼠尾草绿、普鲁士海军蓝、炭靛蓝、暖灰褐、赭石卡其、尘砖色、板岩蓝、深橄榄绿
- 保持组合狭窄：相关或相邻色相讲述一个色彩故事。绝无彩虹

高光引擎：
- 每幅图像恰好一种饱和高光色——全图唯一的高饱和色
- 可以是任何色相：朱红、番茄红、万寿菊黄、钴蓝、翠鸟蓝、品红、黄绿色
- 承担构图任务：焦点物体（约画布1-6%）或结构线颜色（约画布3-10%）
- 移除测试：心理删除高光，如果视线路径、平衡和场景小故事保持不变，它就是装饰——重新设计它

**人物系统：**
- 人物是小型实心剪影，**绝非火柴人**
- 每人约画布高度的1.5-5%，由3-7个填充平涂形状组成
- 实心躯干、有可见宽度的四肢、实心块状或点状头部
- 细线四肢和轮廓圆头（火柴人）是风格的硬性失败
- 绝无面部特征。头部是实心空白点或简单填充形状；身份来自姿态和活动
- 从场域卡片中绘制活动中的他们：提着包行走、踩踏板、扔球、坐着阅读、遛狗
- 僵硬、认真、仿朴素——绝不可爱、绝不Q版、绝无卡通比例
- 散布3-20个人物，间距不均、方向各异
- 服装是从区域色调和锚点中选取的不透明平涂填充

**构图家族：**
- **分层地带**（默认）：世界堆叠为2-5个水平或轻微对角的平涂色带。空间是地质，而非透视。色带可倾斜5-20°以产生动感。
- **图鉴散点**：元素漂浮在开放的纸面上，如目录页——各自独立绘制，无共享地面，无统一透视。保持约40-65%的开放纸面。

**布局规则：**
- 仅2-5个区域。一个区域应占主导（约占画布35-60%）；无偶然的50/50分割
- 建立一条视线路径：从最大区域的最密集角落进入，遇见高光，沿着主导动势移动，从较安静的区域退出
- 密度对撞：将极度密集的质感块直接压在简洁的平涂区域旁。对比本身就是戏剧；不要用渐变或雾气软化边界

**硬性禁止：**
- 线性透视、消失点、透视缩短、地平线雾气、大气深度
- 3D渲染、投射阴影、软阴影、渐变
- 光滑矢量清洁感、绘画笔触、水彩晕染
- 摄影像素或质感、照片写实区域、电影光线、景深
- 人物面部特征、火柴人、细线四肢或线描人物
- 真人肖像、可爱卡通/Q版/动漫比例、儿童读物甜美感
- 第二套饱和色系统、彩虹或糖果色调、柔和色调
- 默认角落日月圆盘、从示例复制的色相或母题
- 霓虹、分层地带中的稀疏白色极简
- 区域内的不均匀或混合质感
- 浅色区域上的白色贴纸轮廓

**故事感：**
- 朴素民间艺术
- 密集而安静
- 从容日常
- 友善的距离

### 潘通相框海报

**视觉特征：**
- 白色相框、主体自然穿框、低饱和背景、潘通式色号标签
- 高级编辑感的摄影海报设计
- 三层空间关系：背景、框内照片、框前主体
- 克制的穿框效果

**色彩参数：**
- 相框：白色或暖白色
- 背景：从照片主色提取，高明度、低饱和
- 色号标注：1-4种视觉近似潘通色号
- 整体：低对比、柔和、高级感

**质感参数：**
- 照片：真实摄影质感，保持清晰
- 阴影：轻微接触阴影
- 文字：清晰无衬线、单层纯黑
- 整体：干净、克制、高级

**构图特征：**
- 三层关系明确：背景层、相框内照片层、穿框元素层
- **必须有元素穿出相框**：选择主体的关键部分自然突破相框边界
- 穿框元素要有轻微接触阴影，增强立体感
- 底部保留充足文字区域
- 画布四周安全留白

**文字规则：**
- 格式：`2995 C · COASTAL BLUE`（潘通色号 + 简洁英文色名）
- 字体：无衬线字体
- 颜色：单层纯黑
- 禁止：倒影、投影、光晕、浮雕、模糊重影

**不同主体的处理：**
- 荷花和叶片：保留纹理清晰度，少量置于相框前
- 海浪和沙滩：少量浪尖跨出内框，海平线稳定
- 云层和晚霞：云缘断续、松散、自然
- 花朵和树枝：保留主干和自然生长方向
- 人物和动物：最清楚的轮廓或动态穿框

**故事感：**
- 高级编辑感
- 克制美学
- 现代设计
- 品牌视觉

## 五、时间质感风格

### 老照片

**色彩参数：**
- 色调：棕褐色/深褐色偏移
- 饱和度：降低 40-60%
- 对比度：降低 20-30%
- 色温：暖色调偏移 +10 到 +20

**质感参数：**
- 颗粒：胶片颗粒，ISO 400-800 感觉
- 划痕：随机细线，覆盖率 5-15%
- 边缘晕影：四角暗角，强度 20-40%
- 褪色程度：高光区泛白，阴影细节丢失

**年代感配置：**
- 1950年代：深褐色、明显颗粒、边缘晕影强
- 1970年代：棕褐色、中等颗粒、开始褪色
- 1990年代：轻微褪色、颗粒细腻、保存较好

**提示词示例：**
```
棕褐色调、胶片颗粒、轻微划痕、边缘暗角、褪色效果、低对比度、历史照片质感、记忆感。
```

### 泛黄信纸照片

**色彩参数：**
- 底色：米黄/淡黄色
- 墨水：褪色深褐/灰黑色
- 饱和度：极低

**质感参数：**
- 纸张纹理：可见纤维纹理
- 褶皱：随机折痕
- 墨迹晕染：边缘模糊扩散
- 边缘：不规则撕裂或磨损

### 报纸印刷

**色彩参数：**
- 模式：黑白或单色
- 半色调：可见网点图案
- 网点密度：根据明暗变化

**质感参数：**
- 网点图案：圆形或菱形网点
- 纸张纹理：新闻纸粗糙感
- 油墨不均：随机深浅变化

## 二、绘画质感风格

### 铅笔画

**线条参数：**
- 工具：石墨铅笔 (HB-6B)
- 线条：灰色调、粗细变化
- 阴影：斜线交叉表现
- 深浅：石墨密度决定

**质感参数：**
- 纸张纹理：可见素描纸纹理
- 笔触方向：可见运笔方向
- 擦拭痕迹：高光区有擦拭感
- 边缘：柔化、有模糊过渡

**铅笔硬度效果：**
- H系列：线条细腻、浅灰色、精确
- HB：中等深度、平衡
- B系列：线条深黑、粗犷、表现力强

### 炭笔画

**线条参数：**
- 工具：炭笔
- 线条：深黑、粗犷
- 阴影：大面积涂抹
- 对比：强烈黑白对比

**质感参数：**
- 颗粒感：明显炭粉颗粒
- 指抹痕迹：模糊边缘
- 粗糙质感：画布或粗糙纸面

### 只此青绿

**灵感来源：**
- 北宋王希孟《千里江山图》
- 舞蹈诗剧《只此青绿》

**核心特征：**
- 基于参考图生成简化版画风格的印记图像，采用青绿山水色彩系统
- 不保留原图照片，只提取主体结构转化为版画印记
- 不是整体色调变化，而是分元素类型分配色彩

**视觉处理（参考东方故事）：**
- 底色：绢白/米白色绢本质感
- 印记风格：现代版画语言
  - 平涂色块
  - 柔化边缘
  - 负空间切割
  - 稀疏线条
- 留白：大量留白，主体占画面宽度 35-55%
- 主体简化为可识别轮廓

**色彩分配规则：**
- 建筑/主体结构 → 石青蓝、石绿（主色调）
- 水面/流动元素 → 淡青、绢白或留白
- 植被/辅助元素 → 石绿、深绿
- 人物/细节 → 赭石、朱砂、金色点缀
- 阴影/轮廓 → 深青、墨色

**色彩参数：**
- 主色调：石青蓝 (#1A365D)、石绿 (#2F855A)
- 辅助色：赭石 (#8B7355)、朱砂红 (#C53030)
- 点缀色：金色 (#D69E2E)
- 底色：绢白或米白
- 特征：不同元素色彩分明，层次分明

**质感参数：**
- 底面：绢本质感
- 颜料：矿物颜料，厚重与通透并存
- 整体：宫廷富丽感

**重要区分：**
- ❌ 不是整体色调变化或滤镜
- ❌ 不是传统青绿山水画（不添加山、石、云、水等新元素）
- ✅ 是完全重新生成的版画风格图像

**硬性禁止：**
- 禁止添加山、石、云、水、雾等任何新元素
- 禁止整体色调统一变化（必须是分元素设计）
- 禁止泛黄、做旧、复古风格
- 禁止保留摄影像素或照片写实区域

**故事感：**
- 东方古典美学
- 宫廷富贵气象
- 山河入画
- 青绿永恒

### 白描画

**线条参数：**
- 工具：毛笔/墨线

### 油画

**色彩参数：**

## 四、材质质感风格

### 沙画

**形态参数：**
- 特征：散点构成、边缘模糊
- 边界：沙粒散落、无清晰边缘

**色彩配置：**
- 沙土色：土黄、褐色、灰色

**形态参数：**
- 特征：剪影、镂空
- 连接：必需连接点
- 边缘：剪刀痕迹

**质感参数：**
- 纸张：剪纸专用纸质感
- 边缘：略微毛糙
- 折痕：可能有折叠痕迹
- 厚度：可见纸张厚度

**色彩配置：**
- 单色：传统红色或黑色
- 彩色：有限配色
- 对比：通常高对比

### 刺绣

**形态参数：**
- 特征：绣线构成的图案
- 针脚：可见运针方向
- 层次：可能有立体感
- 细节：受绣线限制

**质感参数：**
- 绣线：丝线或棉线质感
- 织物底：可见布纹
- 针孔：针脚穿孔
- 光泽：丝线有光泽

**色彩配置：**
- 绣线配色：传统或现代
- 渐变：用不同色线表现
- 层次：叠加绣线

### 蜡笔画

**视觉特征：**
- 粗犷笔触、蜡质肌理、涂抹痕迹、儿童画感
- 不追求精细，重在表达
- 童趣天真的氛围

**色彩参数：**
- 主色调：浓郁鲜艳的色彩
- 特征：蜡笔特有的颜色质感
- 饱和度：高饱和，鲜艳
- 对比度：中等

**质感参数：**
- 笔触：粗犷、有方向感
- 蜡质：光泽感、颗粒感
- 涂抹：可见的重叠和涂抹痕迹
- 纸张：纹理清晰可见

**笔触特征：**
- 边缘：蜡笔特有的颗粒边缘
- 粗细：不均匀，有轻重
- 重叠：色彩叠加效果
- 擦拭：可能有擦拭痕迹

**故事感：**
- 童趣
- 天真
- 童年记忆
- 纯真

### 马赛克

**形态参数：**
- 特征：方块拼接
- 间隙：可见嵌缝
- 边缘：方块锯齿
- 细节：方块大小决定

**质感参数：**
- 方块：玻璃、石材或陶瓷质感
- 间隙：水泥或粘合剂
- 光泽：材质决定
- 纹理：方块表面纹理

**色彩配置：**
- 色块：有限颜色组合
- 渐变：用不同色块模拟
- 整体：远看连续，近看离散

## 五、数字质感风格

### 像素艺术

**形态参数：**
- 分辨率：低分辨率（如 32x32, 64x64）
- 像素：可见像素方块
- 边缘：锯齿状
- 细节：像素级简化

**质感参数：**
- 方块：清晰像素边界
- 颜色：受限调色板
- 锯齿：边缘特征

**色彩配置：**
- 调色板：8色、16色或自定义
- 无渐变：或用抖动模拟
- 饱和度：通常较高



### 故障老照片

**形态参数：**
- 特征：老照片 + 数字故障混合
- 褪色：棕褐色调
- 故障：RGB分离、撕裂
- 噪点：胶片颗粒 + 数字噪点

**质感参数：**
- 双重质感：物理磨损 + 数字故障
- 撕裂：画面局部撕裂
- 色块：RGB通道错位

**色彩配置：**
- 棕褐色 + RGB偏移
- 褪色 + 异常色彩

## 六、自然质感风格

### 树叶拼贴

**形态参数：**
- 特征：用树叶形状拼贴
- 边缘：叶形轮廓
- 层次：叶片叠加
- 细节：受叶形限制

**质感参数：**
- 叶脉：可见叶脉纹理
- 边缘：枯叶边缘
- 颜色：自然叶色

**色彩配置：**
- 秋叶色：黄、橙、红、褐
- 绿叶色：不同绿色调
- 枯叶色：褐色、灰色

### 光影投影

**形态参数：**
- 特征：光线穿透形成的投影
- 边缘：柔和渐变
- 层次：多重投影叠加
- 细节：受光源影响

**质感参数：**
- 渐变：柔和过渡
- 边缘：模糊边界
- 层次：透明叠加

**色彩配置：**
- 单色光：黑白投影
- 彩色光：RGB投影
- 自然光：暖黄投影

```
│  └─ 东方感 → 白描画

├─ 建筑风景

│  └─ 东方感 → 白描画、浮世绘
│
├─ 自然风景
│  ├─ 梦幻感 → 水彩画、沙画
│  ├─ 自然感 → 树叶拼贴
│  └─ 光影感 → 光影投影
│
├─ 静物器物
│  ├─ 精致感 → 铅笔画、白描画

│
└─ 街景纪实
   ├─ 历史感 → 老照片、报纸印刷
   ├─ 现代感 → 像素艺术
   └─ 艺术感 → 铅笔速写、丝网印刷
```
