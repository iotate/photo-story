# 敦煌壁画

## 核心特征
- 基于参考图生成简化壁画风格的印记图像，采用敦煌色彩系统
- 不保留原图照片，只提取主体结构转化为壁画印记
- 不添加额外内容，不添加佛像、飞天、藻井、云纹、花纹等敦煌特有元素

## 风格DNA
1. **敦煌色彩**：朱砂红、石青蓝、石绿、土黄为主色调
2. **壁画底色**：土黄/赭石色壁画底色
3. **铁线描**：流畅有力的铁线描
4. **矿物颜料**：平涂色块，矿物颜料质感
5. **斑驳质感**：壁画肌理，斑驳、龟裂痕迹
6. **金色点缀**：细节点缀金色

## 技术参数

### 色彩参数
- 主色调：朱砂红、石青蓝、石绿、土黄
- 点缀色：金箔
- 底色：土黄或赭石色壁画底
- 对比：色彩对比强烈

### 质感参数
- 壁画肌理：斑驳、龟裂痕迹
- 矿物颜料：厚实感
- 线条：铁线描，流畅有力

### 构图特征
- 主体简化为可识别轮廓
- 平涂色块
- 流畅有力的铁线描
