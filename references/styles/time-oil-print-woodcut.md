# 油印版画

## 核心特征
- 将同一场景重构为极简、克制、具有手工印刷质感的单色版画
- 只使用一个取自原图的主色，配合暖白纸面与少量同色深墨层次
- 不是照片滤镜，不是整张照片单色描摹，不是写实主体贴到纸上，也不是抠出主体后清空背景

## 风格DNA
1. **单色版画**：极简、克制的单色版画，不是照片滤镜
2. **手工印刷**：具有手工印刷质感，不是整张照片单色描摹
3. **场景骨架**：保留场景骨架，不是写实主体贴到纸上，也不是抠出主体后清空背景
4. **先留白再落笔**：约一半或更多的连续纸白，不用密集浅网点假装留白
5. **疏密明确**：主体清晰但不过度放大，背景可辨但明显简化
6. **自然生长**：线条顺着场景自然生长，不使用机械图案

## 技术参数

### 色彩参数
- 只使用一个取自原图的主色
- 暖白纸面与少量同色深墨层次
- 单色美学

### 质感参数
- 细腻纸张纤维可见
- 轻微油墨不均
- 粗粝网点
- 少量印刷错位
- 禁止：光滑渐变、摄影式阴影、3D质感、塑料质感、浓重污渍或满纸噪点

### 构图特征
- 约一半或更多的连续纸白
- 纸白不仅在四周，也要进入景物内部与景物之间
- 天空、云雾、开阔水面和非重点区域优先留白
- 不用密集浅网点假装留白，不让碎纹理铺满画面

## 提示词模板
```
将照片转换为油印版画风格。

【核心设定】
将同一场景重构为极简、克制、具有手工印刷质感的单色版画。只使用一个取自原图的主色，配合暖白纸面与少量同色深墨层次。不是照片滤镜，不是整张照片单色描摹，不是写实主体贴到纸上，也不是抠出主体后清空背景。

【保留场景骨架】
识别原图核心主体，以及识别场景所必需的背景，如山脉、岸线、树林、道路、田野、建筑、水面等；保留它们的相对位置、尺度关系、主要轮廓与透视走向，让人一眼看出与上半部分是同一场景。主体清晰但不夸张放大，背景可辨但明显简化，只保留原图中真实存在的元素，不添加无关景物。

【先留白，再落笔】
下半幅应有约一半或更多的连续纸白，纸白不仅在四周，也要进入景物内部与景物之间。天空、云雾、开阔水面和非重点区域优先留白，不用密集浅网点假装留白，不让碎纹理铺满画面。

【疏密关系明确】
主体及其邻近区域最清晰、纹理最集中；越远离主体，线条越少、越断裂，颗粒越稀疏，最终自然消散到纸白。不要闭合所有轮廓，不要把每个区域都填满。

【线条顺着场景自然生长】
只选一种主要组织逻辑：水面用顺透视的横纹、局部弧线与必要倒影；道路或田野顺着弯曲走向和地形延展；山地顺山脊与坡面组织稀疏纹理；建筑沿轮廓和结构节奏形成断续延伸；若主体有明确运动，可沿真实方向组织断线与颗粒。不要机械同心圆、放射光环、雷达线、刻度、重复残影或强行速度拖尾。

【质感呈现】
整体呈现细腻纸张纤维、轻微油墨不均、粗粝网点与少量印刷错位；不用光滑渐变、摄影式阴影、3D、塑料质感、浓重污渍或满纸噪点。
```

## 适用场景
- 风景摄影：山水、海岸、田野、自然风景
- 城市景观：城市街道、建筑群、城市肌理
- 建筑摄影：建筑外观、建筑群、空间结构
- 人物场景：人物与环境的场景叙事
- 自然场景：森林、山脉、水面、天空

## 反模式
- 照片滤镜

- 写实主体贴到纸上
