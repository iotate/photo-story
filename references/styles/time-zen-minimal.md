# 禅意简笔画

## 核心特征
- 极简东方禅意水墨素描
- 几笔黑色毛笔线条 + 一个朱红色点缀
- 冷色调米白色粗糙水彩纸
- 只基于原图内容简化，不添加原图中没有的元素

## 风格DNA
1. **纸张**：冷色调米白色粗糙水彩纸，清晰可见的浮雕纹理，左上角斜射光
2. **线条**：黑色毛笔线条，粗细变化，干笔起收，墨迹在纸张脊线上略微断开
3. **简化**：每个部分一笔轮廓，无阴影、无纹理、无细节线
4. **色彩**：黑色 + 一个朱红色点缀，总面积<5%，印章式颗粒质感
5. **留白**：无背景、无地平线、无天空，主体占据画面40-60%
6. **格式**：默认竖版3:4，动物侧影和宽场景用横版4:3

## 技术参数

### 色彩参数
- 黑色毛笔线条
- 一个朱红色点缀（总面积<5%）
- 朱红色选择优先级：
  - 照片中已有红色/暖色的小物件（灯笼、花朵、铃铛、项圈、丝带）
  - 自然的焦点（太阳、月亮、一个果实、一只鸟）
  - 主体最小、最远的部分（远处的塔、远山）
  - 备选：一个小太阳

### 质感参数
- 冷色调米白色粗糙水彩纸
- 清晰可见的浮雕纹理
- 左上角斜射光
- 墨迹在纸张脊线上略微断开
- 干笔飞白效果

### 构图特征
- 无背景、无地平线、无天空
- 主体占据画面40-60%
- 每个部分一笔轮廓
- 简化原则：保留主体、姿态、位置，删除背景、地面、天空、房间

## 提示词模板
```
将照片转换为禅意简笔画风格。

【硬性要求】
只基于原图内容简化，不添加原图中没有的任何元素。禁止添加竹枝、竹叶、梅花、松枝等装饰性植物，禁止添加装饰纹样、印章、题字。

【纸张】
冷色调米白色粗糙水彩纸，清晰可见的浮雕纹理，左上角斜射光给每个凸起一个小高光和旁边的灰色凹坑。

【线条】
黑色毛笔线条，粗细变化，自信有力的主线，细节细线，起笔和收笔处有干笔飞白效果，墨迹坐在纸张脊线上并在凹坑处略微断开。绝非均匀的数字轮廓线。

【简化】
每个部分一笔轮廓。无交叉阴影、无毛发羽毛、无叶脉、无阴影、无内部细节线。只画原图中有的内容。

【色彩】
黑色 + 一个朱红色点缀（总面积<5%）。朱红色点缀为1-5个小块，印章式颗粒质感，无渐变。

【留白】
无背景、无地平线、无天空。主体坐在一侧，占据画面40-60%。只保留原图中已有的元素，删除所有其他元素。

【格式】
默认竖版3:4；动物侧影和宽场景用横版4:3。

【主体处理】
保留原图主体、姿态和位置，删除所有其他元素包括地面、天空和房间。明确指定朱红色点缀位置。只画原图中有的内容，不添加任何装饰元素。
```

## 适用场景
- 动物、花卉、建筑、人物、静物

## 反模式
- 背景轮廓、地面、天空或地平线仍然可见
- 灰色晕染、阴影、渐变，"水墨画"的柔和感而非清晰线条
- 交叉阴影、毛发羽毛纹理、叶脉、内部细节线
- 统一的数字轮廓，无粗细变化或干笔末端
- 纸张呈现为灰泥墙（有透视）或纯白（无纹理）
- 红色出现在比预期更多的位置，或红色渐变，或红色填充整个主体
- 添加了原图中没有的装饰元素（竹枝竹叶、花卉等）
