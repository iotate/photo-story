# 没骨画

## 核心特征
- 不用墨线勾勒轮廓，直接用色彩或墨色渲染
- 色彩柔和过渡，无明显线条边界
- 画面柔和、含蓄、雅致

## 风格DNA
1. **无轮廓线**：不用墨线勾勒轮廓
2. **色彩渲染**：直接用色彩或墨色渲染形体
3. **柔和过渡**：色彩柔和过渡，无明显线条边界
4. **明暗表现**：通过色彩浓淡表现明暗
5. **宣纸质感**：宣纸或绢本质感
6. **虚实相生**：虚实相生的画面效果

## 技术参数

### 色彩参数
- 主色调：根据原图内容分配色彩
- 特征：柔和雅致的色彩
- 饱和度：中低，温和
- 对比度：低对比，柔和

### 质感参数
- 底面：宣纸或绢本质感
- 渲染：色彩晕染效果
- 边界：无明显线条边界
- 整体：柔和、含蓄

### 构图特征
- 适度留白
- 保持画面透气感
- 东方美学呼吸感
- 根据题材灵活调整：花卉鸟虫40-60%，山水人物50-70%

## 提示词模板
```
将照片转换为没骨画风格。保留原图的主体形态和构图，用没骨画技法呈现：不用墨线勾勒轮廓，直接用色彩或墨色渲染，色彩柔和过渡，无明显线条边界。宣纸或绢本质感，适度留白保持画面透气感，整体呈现东方的柔和含蓄之美。
```
