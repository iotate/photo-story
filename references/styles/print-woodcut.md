# 木刻版画

## 核心特征
- 提取照片主体、轮廓、姿态与叙事关系，重构为限色木刻版画印记
- 木刻版画、油毡版画、手工套印的语言
- 朴拙、笨拙、手工感强烈

## 风格DNA
1. **主体提取**：主动删减复杂背景与细碎信息，只保留决定识别度的轮廓、比例、方向、明暗分区
2. **手作痕迹**：刀刻般的笨拙感，线条不必光滑精确，允许迟疑、粗细不均、边缘发毛、断裂、缺口
3. **限色逻辑**：柔和、治愈、明亮的限色系统，低至中等饱和度、高明度与柔和对比
4. **留白构图**：大面积温暖的纸张留白，不完整边缘，像被轻轻压印在纸面上的记忆
5. **手工质感**：色块边缘呈现干刷、漏印、缺墨和粗颗粒纹理，非精致矢量插画
6. **文字构图**：文字作为版画构图的一部分，与图形形成承托、穿插、错位或呼应关系

## 技术参数

### 色彩参数
- 色系选择：奶油白、象牙白、浅粉、雾绿、浅蓝、嫩黄、淡橙、薄荷绿、柔和珊瑚色、浅赭石
- 配色原则：干净而轻盈的综合色系，低至中等饱和度、高明度与柔和对比
- 记忆点保留：保留原图最动人的色彩记忆点
- 避免灰暗：避免灰暗、沉闷、脏旧、厚重和过度复古的配色
- 油墨质感：像哑光实体油墨层层套印，柔和清透，有版画的颗粒与温度

### 质感参数
- 刀刻感：刀刻般的轻微迟疑、粗细不均
- 边缘发毛：边缘不必光滑精确，允许发毛
- 转折生硬：转折处可以生硬、不圆润
- 局部断裂：允许局部断裂、缺口、错位
- 不规则留白：不规则留白，像手工刻印
- 干刷漏印：色块边缘呈现干刷、漏印、缺墨
- 粗颗粒纹理：粗颗粒纹理，版画质感

### 构图特征
- 单一锚点：以单一视觉锚点为核心
- 大面积留白：主体周围保留充分的温暖纸张留白
- 不完整边缘：边缘通过缺墨、断裂纹理、纸张透底逐渐消失
- 避免边框：避免完整矩形边框
- 位置灵活：根据主体视觉重心、动作方向决定位置与尺度，可居中、偏置、轻微裁切

## 提示词模板
```
将照片转换为木刻版画风格。

【主体提取】
提取照片中最具识别性的主体、轮廓、姿态与叙事关系。不要直接复制整张照片，也不要简单套用滤镜，而是主动删减复杂背景与细碎信息，只保留决定识别度的轮廓、比例、方向、明暗分区、关键结构与核心空间关系，以木刻版画、油毡版画和手工套印的语言重新概括主体，使其一眼可辨，同时具有朴拙、笨拙、手工感强烈的艺术气质。

【笔触特征】
图形笔触要带有木刻版画特有的笨拙感与手作痕迹：线条不必光滑精确，允许出现刀刻般的轻微迟疑、粗细不均、边缘发毛、转折生硬、局部断裂、缺口、错位和不规则留白；色块边缘可呈现干刷、漏印、缺墨和粗颗粒纹理。整体不是精致矢量插画，而是像用手工刻刀和油墨一刀一刀刻印出来，带着朴素、直接、略微稚拙却非常耐看的版画气质。

【限色系统】
配色从照片中提取最具辨识度和生命力的颜色，但整体转化为小清新、柔和、治愈、明亮的限色逻辑。采用奶油白、象牙白、浅粉、雾绿、浅蓝、嫩黄、淡橙、薄荷绿、柔和珊瑚色、浅赭石等干净而轻盈的综合色系，保持低至中等饱和度、高明度与柔和对比。保留原图最动人的色彩记忆点，但避免灰暗、沉闷、脏旧、厚重和过度复古的配色。所有颜色应像哑光实体油墨层层套印，柔和清透，却仍有版画的颗粒与温度。

【留白构图】
构图以单一视觉锚点、大面积留白和不完整边缘为核心，根据主体自身的视觉重心、动作方向和结构走势决定位置与尺度，可居中、偏置、轻微裁切或沿某一方向延展。主体周围保留充分的温暖纸张留白，边缘通过缺墨、断裂纹理、纸张透底和自然磨损感逐渐消失，避免完整矩形边框，让画面像一段被轻轻压印在纸面上的记忆。

【文字融入】
文字同样作为版画构图的一部分介入，而不是固定说明文字。从照片的主体身份、动作、情绪、状态、地点或隐喻中提炼一个1-3词的主标题，并搭配一组极短关键词或微型说明。主标题可沿主体轮廓、留白边界、视觉轴线或版画边缘排列，与图形形成承托、穿插、错位或呼应关系；辅助小字保持细小、克制，采用打字机体、等宽衬线体或旧档案式排版，像旅行笔记或私人收藏版画中的注释。不要固定使用年份，让文字根据照片本身自然生长。

【整体气质】
整体强调木刻版画的朴拙手感、清新柔和的限色、纸张留白、不完整边缘与克制排版，呈现温暖、安静、治愈、轻盈、怀旧而不灰暗的高级版画气质。无论主体是人物、动物、植物、建筑、器物、交通工具或自然景观，都应保持真实摄影与版画重构之间清晰而巧妙的视觉呼应，避免普通滤镜、完整背景复刻、光滑矢量描边、卡通插画、旅游模板感和廉价复古感。
```
