# 浅绛山水

## 核心特征
- 水墨为骨、淡雅设色、清秀淡泊
- 文人画风格，以淡赭石、花青为主
- 不同于青绿山水的浓丽，追求淡雅意境
- 诗书画印结合

## 风格DNA
1. **水墨为骨**：以水墨勾勒骨架
2. **淡雅设色**：浅淡赭石和花青渲染
3. **清秀淡泊**：淡雅清秀的画面气质
4. **文人笔意**：逸笔草草，不求形似
5. **诗书画印**：诗书画印结合
6. **宣纸质感**：宣纸质感，淡雅渲染

## 技术参数

### 色彩参数
- 主色调：赭石、花青、淡墨
- 辅助色：淡黄、淡绿
- 底色：宣纸白或米黄
- 渐变：淡雅渲染

### 质感参数
- 笔触：文人画笔法，逸笔草草
- 纹理：宣纸质感
- 渲染：淡雅水墨晕染
- 留白：云雾、水面、天空

### 构图特征
- 三远法构图
- 散点透视
- 山石以淡墨勾勒
- 树木、建筑点缀
- 主体占画面30-50%，留白50-70%

## 提示词模板
```
将照片转换为浅绛山水风格。保留原图的主体结构，用文人画技法呈现：水墨勾勒骨架，浅淡赭石和花青渲染，淡雅清秀。宣纸质感，大量留白（占画面50-70%），营造淡泊宁静的意境，整体呈现文人的淡泊与清雅。
```
