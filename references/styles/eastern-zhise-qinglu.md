# 只此青绿

## 核心特征
- 基于参考图生成简化版画风格的印记图像，采用青绿山水色彩系统
- 不保留原图照片，只提取主体结构转化为版画印记
- 不是整体色调变化，而是分元素类型分配色彩

## 风格DNA
1. **青绿色彩系统**：以石绿系列为主色调，根据元素类型分配色彩
   - 石绿沉 #163A2E：山体暗部、建筑阴影
   - 石绿 #2E5E4A：主要山体、建筑主体
   - 孔雀石 #4A8A6E：受光面、植被
   - 金绿 #9ABA8E：过渡区域、水面
   - 金箔 #E8C870：建筑细节、装饰点缀
2. **绢本质感**：绢白/米白色绢本质感底色
3. **版画语言**：平涂色块、柔化边缘、负空间切割、稀疏线条
4. **分元素着色**：建筑/山体→石绿系列；水面→金绿、绢白；植被→孔雀石
5. **大量留白**：主体占画面宽度 35-55%
6. **宫廷富丽**：东方古典宫廷美学

## 技术参数

### 色彩参数
- **优先颜色**（按使用顺序）：
  - 石绿沉 #163A2E（深邃的墨绿色，用于山体暗部、建筑阴影）
  - 石绿 #2E5E4A（经典石绿色，用于主要山体、建筑主体）
  - 孔雀石 #4A8A6E（明亮的青绿色，用于受光面、植被）
  - 金绿 #9ABA8E（淡雅的黄绿色，用于过渡区域、水面）
  - 金箔 #E8C870（金色点缀，用于建筑细节、装饰元素）
- 辅助色：赭石 (#8B7355)、朱砂红 (#C53030)
- 底色：绢白或米白
- 特征：不同元素色彩分明，层次分明，色彩过渡自然

### 质感参数
- 底面：绢本质感
- 颜料：矿物颜料，厚重与通透并存
- 整体：宫廷富丽感
- 印记风格：现代版画语言
  - 平涂色块
  - 柔化边缘
  - 负空间切割
  - 稀疏线条

### 构图特征
- 主体简化为可识别轮廓
- 大量留白
- 主体占画面宽度 35-55%

```
色彩系统（优先使用）：
- 石绿沉 #163A2E：山体暗部、建筑阴影
- 石绿 #2E5E4A：主要山体、建筑主体
- 孔雀石 #4A8A6E：受光面、植被
- 金绿 #9ABA8E：过渡区域、水面
- 金箔 #E8C870：建筑细节、装饰点缀

```

## 适用场景
- 建筑、地标、天际线、桥梁
- 有清楚轮廓、强光影的场景
- 适合制作系列艺术作品

## 反模式
- 整体色调变化或滤镜
- 传统青绿山水画（添加山、石、云、水等新元素）
- 泛黄、做旧、复古风格
- 保留摄影像素或照片写实区域

## 故事感
- 东方古典美学
- 宫廷富贵气象
- 山河入画
- 青绿永恒
