# 风格转换技术细节参考

本文件提供各种风格的技术参数和转换细节，确保风格化转换的质量和一致性。

## 核心原则

### 结构保留清单

在所有风格转换中必须保留：

1. **主体位置**：主要元素在画面中的相对位置不变
2. **大小比例**：元素之间的大小关系不变
3. **构图框架**：三分、对称、中心等构图结构不变
4. **空间层次**：前景、中景、背景的关系不变
5. **轮廓识别**：主体的外形能够被识别

### 风格转换清单

在风格转换中必须改变：

1. **色彩系统**：色调、饱和度、对比度根据风格调整
2. **质感细节**：纹理、颗粒、笔触根据风格添加
3. **线条处理**：清晰度、风格化程度根据风格调整
4. **边缘处理**：锐利、柔和、风格化边缘

## 一、东方故事风格（默认）

### 东方故事

**核心特征：**
- **基于参考图生成简化版画风格的印记图像**
- 不保留原图照片，只提取主体结构转化为版画印记
- 暖象牙白/米白色纸张底色
- **保留原图特征性色彩，调整为东方美学色调**
- 现代版画语言 + 东方克制美学

**关键区别（避免误读）：**
- ❌ 不是整张照片做旧、泛黄或上色
- ❌ 不是银盐相纸、手工上色、复古摄影
- ❌ 不是纯黑白或深墨色印记
- ✅ 是完全重新生成的版画风格图像，保留特征性色彩

**结构参数：**
- 布局：竖版图像，单一画面
- 底色：暖象牙白 #F5F0E6、米白色 #FAF8F5、或安静的源光色调
- 整体：纸张质感的平面，承载简化的主体印记

**色彩参数：**
- 底色：暖象牙白、米白色
- **特征性色彩**：保留原图的主要色彩，调整为东方美学色调
  - 红色系 → 朱砂红 #C53030、胭脂红
  - 蓝色系 → 石青蓝 #1A365D、靛蓝
  - 黄色系 → 藤黄 #D69E2E、赭石褐
  - 绿色系 → 石绿、青碧
  - 紫色系 → 紫檀、青莲
- **禁止**：泛黄、做旧、复古色调、完全黑白化

**质感参数：**
- 画面质感：干净纸张质感，轻微纹理，不喧闹
- 印记风格：现代版画语言
  - 平涂色块（solid color blocks）
  - 柔化边缘（softened edges）
  - 负空间切割（negative-space cuts）
  - 稀疏线条（sparse lines）
  - 有节制的断点（measured breaks）
- 留白：大量留白，印记不填满画面
- **禁止**：厚重纹理、粗糙颗粒、仿旧效果

**印记语法：**
- 主要形态：一个清晰可识别的主体印记（占画面宽度 35-55%）
- 辅助印记：极少量支持性印记
  - 基座线条
  - 地平线/地面
  - 比例标记（人物用小垂直刻痕）
- 细节转换规则：
  - 屋顶层次 → 2-4 条堆叠弧线，保留原有色彩
  - 窗户 → 3-5 个稀疏小点或短切口
  - 人物 → 3-8 个小垂直刻痕（无脸、无细节）
  - 水面 → 1-2 条水平残留线
  - 天空/光 → 保留为纸张留白，或用淡雅色彩暗示
- **禁止**：复杂细节、装饰性元素、写实描绘

**风格参照：**
- 现代平面设计中的极简版画
- 东方美学的留白与克制
- 传统中国画色彩体系
- 编辑设计中的系列艺术海报
- **不是**：复古摄影、手工上色、银盐工艺、纯黑白版画

**故事感：**
- 东方美学的诗意化呈现
- 安静、克制、有呼吸感
- 可重复的系列识别度
- 画廊标签般的诗意（可选小标题）

**适用场景：**
- 建筑、地标、天际线、桥梁
- 有清楚轮廓、强光影的场景
- 旅行、城市、自然景观
- 适合制作系列艺术作品

**提示词示例：**
```
基于参考图生成东方故事风格图像。

画面要求：
- 竖版图像，暖象牙白或米白色纸张底色
- 使用现代版画语言呈现简化的主体
- 大量留白，主体占画面宽度 35-55%

色彩处理：
- 保留原图的特征性色彩
- 调整为东方美学色调（朱砂红、石青蓝、赭石褐、藤黄等）
- 色彩简洁、雅致，不喧闹

印记风格：
- 平涂色块，保留特征性色彩
- 柔化边缘，不锐利
- 负空间切割，留白充分
- 稀疏线条，细节极少

风格禁止：
- 禁止泛黄、做旧、复古摄影风格
- 禁止银盐相纸、手工上色
- 禁止厚重纹理、粗糙颗粒
- 禁止完全黑白化、失去特征性色彩
- 禁止复杂细节、装饰元素

整体呈现：东方美学意境、诗意化色彩、留白之美。
```

**变体配方：**

印记语法：
- 墨章建筑：块状形态 + 负空间切割 + 特征性色彩
- 堆叠秩序：弧线、条带、台阶简化为 3-5 个层次，保留色彩
- 天际线记忆：地标主形态 + 2-3 辅助条 + 地平线
- 光影遗珍：主体剪影轻压入柔和光场，保留淡雅色彩
- 边缘残留：4-6 条果断边缘聚集成可识别图案

色彩重量：
- 雅致色块：保留特征性色彩，调整为东方美学色调（默认）
- 淡彩：色彩更淡雅、含蓄
- 重彩：色彩更浓郁、有力量
- 单色：仅用一种特征色 + 纸张底色

## 二、时间质感风格

### 老照片

**色彩参数：**
- 色调：棕褐色/深褐色偏移
- 饱和度：降低 40-60%
- 对比度：降低 20-30%
- 色温：暖色调偏移 +10 到 +20

**质感参数：**
- 颗粒：胶片颗粒，ISO 400-800 感觉
- 划痕：随机细线，覆盖率 5-15%
- 边缘晕影：四角暗角，强度 20-40%
- 褪色程度：高光区泛白，阴影细节丢失

**年代感配置：**
- 1950年代：深褐色、明显颗粒、边缘晕影强
- 1970年代：棕褐色、中等颗粒、开始褪色
- 1990年代：轻微褪色、颗粒细腻、保存较好

**提示词示例：**
```
棕褐色调、胶片颗粒、轻微划痕、边缘暗角、褪色效果、低对比度、历史照片质感、记忆感。
```

### 泛黄信纸照片

**色彩参数：**
- 底色：米黄/淡黄色
- 墨水：褪色深褐/灰黑色
- 饱和度：极低

**质感参数：**
- 纸张纹理：可见纤维纹理
- 褶皱：随机折痕
- 墨迹晕染：边缘模糊扩散
- 边缘：不规则撕裂或磨损

### 报纸印刷

**色彩参数：**
- 模式：黑白或单色
- 半色调：可见网点图案
- 网点密度：根据明暗变化

**质感参数：**
- 网点图案：圆形或菱形网点
- 纸张纹理：新闻纸粗糙感
- 油墨不均：随机深浅变化

## 二、绘画质感风格

### 铅笔画

**线条参数：**
- 工具：石墨铅笔 (HB-6B)
- 线条：灰色调、粗细变化
- 阴影：斜线交叉表现
- 深浅：石墨密度决定

**质感参数：**
- 纸张纹理：可见素描纸纹理
- 笔触方向：可见运笔方向
- 擦拭痕迹：高光区有擦拭感
- 边缘：柔化、有模糊过渡

**铅笔硬度效果：**
- H系列：线条细腻、浅灰色、精确
- HB：中等深度、平衡
- B系列：线条深黑、粗犷、表现力强

### 炭笔画

**线条参数：**
- 工具：炭笔
- 线条：深黑、粗犷
- 阴影：大面积涂抹
- 对比：强烈黑白对比

**质感参数：**
- 颗粒感：明显炭粉颗粒
- 指抹痕迹：模糊边缘
- 粗糙质感：画布或粗糙纸面

### 钢笔画

**线条参数：**
- 工具：钢笔/蘸水笔
- 线条：均匀墨线、无粗细变化
- 阴影：交叉线或点状
- 边缘：锐利清晰

**质感参数：**
- 墨水：深黑或深褐色
- 纸张：光滑纸面
- 无渐变：纯线条表现
- 精确感：技术性描绘

### 白描画

**线条参数：**
- 工具：毛笔/墨线
- 线条：单色墨线
- 特征：无阴影、无色彩、大量留白
- 韵律：书法般的轻重顿挫

**质感参数：**
- 底面：宣纸质感
- 留白：占据画面大部分
- 线条：简洁但有韵味
- 转折：有力、不犹豫

**线条技法：**
- 起笔：轻入
- 行笔：中锋为主
- 收笔：轻出或顿住
- 转折：方折或圆转

### 水彩画

**色彩参数：**
- 特性：透明、叠加
- 边缘：水渍痕迹
- 色彩：柔和、渐变
- 透明度：高

**质感参数：**
- 水痕：边缘有积水线
- 晕染：颜色自然扩散
- 纸张纹理：水彩纸纹理可见
- 叠加：透明色层叠加

**技法效果：**
- 湿画法：边缘模糊、色彩融合
- 干画法：边缘清晰、层叠效果
- 留白：保留纸面白色
- 撒盐：特殊肌理效果

### 油画

**色彩参数：**
- 特性：浓郁、覆盖性强
- 对比：强烈
- 饱和度：高
- 层次：厚重色层

**质感参数：**
- 笔触：明显可见
- 画布纹理：可见底纹
- 颜料厚度：有立体感
- 刮刀：可能留痕迹

**风格变体：**
- 古典：光滑表面、细腻渐变
- 印象派：明显笔触、光色表现
- 表现主义：粗犷笔触、夸张色彩

## 三、印刷质感风格

### 木刻版画

**线条参数：**
- 特征：块面分明、黑白对比
- 边缘：锐利、有力
- 刀痕：可见雕凿痕迹
- 木纹：可能有纹理显现

**质感参数：**
- 色块：平涂、无渐变
- 对比：强烈黑白
- 线条：粗犷、有力
- 质感：木版压印感

**色彩配置：**
- 单色：黑白最经典
- 套色：2-4色，边缘略有错位
- 油墨：均匀或有纹理

### 丝网印刷

**线条参数：**
- 特征：色块平涂
- 边缘：清晰、可能有轻微错位
- 层次：套色叠加
- 渐变：无或模拟

**质感参数：**
- 墨层：均匀、平滑
- 套色：可见色块边界
- 错位：轻微位移是特征
- 网点：无或极细

**色彩配置：**
- 色数：通常3-6色
- 色彩：鲜艳或做旧均可
- 叠加：透明色套印

### 浮世绘

**线条参数：**
- 特征：轮廓线明确
- 图案：平面装饰性强
- 透视：非西方透视
- 线条：流畅、有韵律

**质感参数：**
- 木版：压印纹理
- 纸张：和纸质感
- 颜料：矿物颜料质感
- 云纹：传统图案

**色彩配置：**
- 传统色：靛蓝、朱红、赭石、淡黄
- 配色：和谐、装饰性
- 渐变：少或用版画技法

## 四、材质质感风格

### 沙画

**形态参数：**
- 特征：散点构成、边缘模糊
- 边界：沙粒散落、无清晰边缘
- 明暗：沙粒密度决定
- 流动：有动感

**质感参数：**
- 颗粒：可见沙粒质感
- 指痕：手指划过的痕迹
- 堆砌：高低不一
- 易逝：有种不稳定感

**色彩配置：**
- 沙土色：土黄、褐色、灰色
- 彩色沙：有限配色
- 渐变：沙粒密度变化

### 剪纸

**形态参数：**
- 特征：剪影、镂空
- 连接：必需连接点
- 边缘：剪刀痕迹
- 层次：平面或多层

**质感参数：**
- 纸张：剪纸专用纸质感
- 边缘：略微毛糙
- 折痕：可能有折叠痕迹
- 厚度：可见纸张厚度

**色彩配置：**
- 单色：传统红色或黑色
- 彩色：有限配色
- 对比：通常高对比

### 刺绣

**形态参数：**
- 特征：绣线构成的图案
- 针脚：可见运针方向
- 层次：可能有立体感
- 细节：受绣线限制

**质感参数：**
- 绣线：丝线或棉线质感
- 织物底：可见布纹
- 针孔：针脚穿孔
- 光泽：丝线有光泽

**色彩配置：**
- 绣线配色：传统或现代
- 渐变：用不同色线表现
- 层次：叠加绣线

### 马赛克

**形态参数：**
- 特征：方块拼接
- 间隙：可见嵌缝
- 边缘：方块锯齿
- 细节：方块大小决定

**质感参数：**
- 方块：玻璃、石材或陶瓷质感
- 间隙：水泥或粘合剂
- 光泽：材质决定
- 纹理：方块表面纹理

**色彩配置：**
- 色块：有限颜色组合
- 渐变：用不同色块模拟
- 整体：远看连续，近看离散

## 五、数字质感风格

### 像素艺术

**形态参数：**
- 分辨率：低分辨率（如 32x32, 64x64）
- 像素：可见像素方块
- 边缘：锯齿状
- 细节：像素级简化

**质感参数：**
- 方块：清晰像素边界
- 颜色：受限调色板
- 锯齿：边缘特征

**色彩配置：**
- 调色板：8色、16色或自定义
- 无渐变：或用抖动模拟
- 饱和度：通常较高



### 故障老照片

**形态参数：**
- 特征：老照片 + 数字故障混合
- 褪色：棕褐色调
- 故障：RGB分离、撕裂
- 噪点：胶片颗粒 + 数字噪点

**质感参数：**
- 双重质感：物理磨损 + 数字故障
- 撕裂：画面局部撕裂
- 色块：RGB通道错位

**色彩配置：**
- 棕褐色 + RGB偏移
- 褪色 + 异常色彩

## 六、自然质感风格

### 树叶拼贴

**形态参数：**
- 特征：用树叶形状拼贴
- 边缘：叶形轮廓
- 层次：叶片叠加
- 细节：受叶形限制

**质感参数：**
- 叶脉：可见叶脉纹理
- 边缘：枯叶边缘
- 颜色：自然叶色

**色彩配置：**
- 秋叶色：黄、橙、红、褐
- 绿叶色：不同绿色调
- 枯叶色：褐色、灰色

### 光影投影

**形态参数：**
- 特征：光线穿透形成的投影
- 边缘：柔和渐变
- 层次：多重投影叠加
- 细节：受光源影响

**质感参数：**
- 渐变：柔和过渡
- 边缘：模糊边界
- 层次：透明叠加

**色彩配置：**
- 单色光：黑白投影
- 彩色光：RGB投影
- 自然光：暖黄投影

