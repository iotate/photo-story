# 水墨插画

## 核心特征
- 米白哑光特种纸质感的水墨扁平重构插画
- 保留原图整体色彩调性
- 兼具随性水墨气韵与干净克制的学术质感

## 风格DNA
1. **纸张质感**：米白哑光特种纸质感底色
2. **色彩调性**：保留原图整体色彩调性
3. **块面造型**：松弛柔和的块面造型，分层平涂
4. **水墨笔触**：随性淡墨晕染笔触，自然松散
5. **轮廓处理**：摒弃生硬轮廓线，自然过渡
6. **留白构图**：大面积留白，主体居中偏上

## 技术参数

### 色彩参数
- 底色：米白哑光特种纸质感
- 色彩调性：保留原图整体色彩调性
- 简化：柔和块面色彩，分层平涂
- 搭配：随性淡墨晕染

### 质感参数
- 纸张：米白哑光特种纸质感
- 水墨：随性淡墨晕染笔触
- 轮廓：自然松散，摒弃生硬轮廓线
- 整体：松弛柔和的块面造型

### 视觉层次
- 底色：米白哑光特种纸质感
- 主体：居中偏上位置，松弛柔和的块面造型
- 水墨：随性淡墨晕染笔触，分层平涂
- 留白：大面积留白，干净克制
- 文字：底部居中，优雅衬线手写标题 + 小号无衬线短句

### 构图特征
- 大面积留白
- 主体放置居中偏上位置
- 底部居中排布文字
- 干净克制的学术质感

### 文字规则
- 位置：底部居中排布
- 首行：优雅衬线手写英文标题
- 第二行：小号无衬线英文短句
- 整体：不添加多余装饰元素
